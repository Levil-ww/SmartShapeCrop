## 十一、关键决策与原则汇总

### 11.1 草图识别核心原则（水池设计器）
1. **轴向cap校验**：边距合理性上限需按轴向分别计算（margin_left/right ≤ outer_w×0.9，margin_top/bottom ≤ outer_h×0.9），避免单一max维度cap导致有效大值被拦截
2. **权威模式优先**：权威模式下应锁定target外框，边距合理性上限应放宽限制
3. **OCR前缀匹配**：正则从精确匹配放宽为前缀匹配（^\d+\.?\d*），处理带单位后缀数值（"74厘米"→74）
4. **_try_bind轴向校验**：Phase3空间绑定必须调用_try_bind执行轴向合理性校验和候选值竞争，禁止直接赋值
5. **物理相邻性检查**：方向字与数值token必须物理相邻（不能仅索引相邻），防止OCR双列蛇形阅读跨列错误配对
6. **方向锁不可覆盖**：方向锁边距不应被后续逻辑（Step6缩放等）覆盖，需添加不变量守护
7. **覆盖不变量收紧**：高conf区间需new_conf比old_conf高≥8点才算可信，防止OCR噪声导致错误覆盖
8. **小数恢复谨慎**：Phase4小数恢复禁止使用硬编码阈值（如30cm）判断路径，避免将有效大整数（74）错误转为小数（7.4）

### 11.2 水池设计器渲染原则
1. **数据契约**：画布尺寸=草图外框+1cm损耗，边距=严格识别值（不加1cm），内挖尺寸=画布尺寸-边距
2. **简单拉伸优先**：参考pack项目使用简单拉伸模式，完整保留源图边框线条不产生黑边（轻微变形可接受）
3. **镜像延展**：边缘延展使用镜像/对称方式替代单点颜色填充，避免突兀色块；小延展量(≤5%)用简单边缘延展
4. **黑边检测**：_estimate_outer_border检测源图黑色边线厚度，cover模式优先避免黑边延展
5. **素材填充跳过边框带**：只要存在任何水池素材（外框或内挖）即跳过边框带渲染，保留背景花纹
6. **方向对齐**：默认信任像素方向，文件名方向与像素方向不一致时以像素方向为准

### 11.3 圆角裁剪核心原则
1. **content_protect_mask**：通过像素颜色距离（>6）区分边框像素和内容像素，仅在非内容像素位置绘制边框色，保护内层花纹
2. **源感知匹配**：删除CORE_BORDER_DEPTH无条件绘实心机制，采用相邻层最小距离+25阈值（BORDER_SIGMA）的源感知匹配
3. **三区域渐进判定**：解决抗锯齿过渡像素误判，容差从+8px降至+2px精确限制validity_mask覆盖范围
4. **内层跳过绘制**：内层color_idx≥1应跳过绘制，避免多余弧线
5. **validity_arr限制清底**：beyond_arc清底范围受validity_arr限制，防止直边像素误判
6. **色差校验区分间隙**：欧式距离>30的色差校验区分误判的过渡/装饰色带与合法间隙层（婉卉奶白底色vs纯白背景）
7. **V1.0简洁策略优先**：V1.0直接绘制策略优于复杂颜色残留清扫逻辑，简化间隙层处理+固定带宽策略

### 11.4 性能与架构原则
1. **LOD分级渲染**：画布像素>100万自动触发LOD，50×70cm@300DPI加速8.7倍
2. **异步分级渲染**：LOD预览立即可见+后台无缝升级全分辨率，避免主线程阻塞
3. **条件触发优化**：各向异性距离场和穷举校验仅在字段缺失/一致性低时触发，主路径0ms开销
4. **跨平台路径封装**：PathResolver类统一资源路径获取+Tesseract-OCR自动检测（Windows/macOS/Linux）
5. **预览导出分级**：预览用BILINEAR（快3-5×），导出用LANCZOS，quality参数控制
