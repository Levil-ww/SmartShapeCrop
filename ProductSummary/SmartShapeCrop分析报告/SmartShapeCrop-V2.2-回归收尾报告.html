B1 实测阶段总结

本轮目标
根据诊断报告"修复路线建议", 优先执行最小改动方案：仅修改 3 处测试文件的圆心常量, 不动任何源码. 通过 trace 已证实 #1 / #4 / #5 / #6 的失败根因是测试几何参数错误, 真实代码在 (R_total, h−R_total) 处的渲染是正确的.
关键诊断证据 (来自实测)

1. 测试环几何错位: 测试用 cx=50, cy=950 作采样圆心, 但 _redraw_border_on_corner 真实圆心是 (R_total, h − R_total) = (177, 823). 测试环 (cx=50, cy=950, dist=52-68) 的全部 306 个采样点在真实圆心看是 dist=117-147 (在 R=177 圆内), 本应在 mask 切圆内被 bg 覆盖, 但实际命中了原图外黑边+灰间隙交界处 — 故断言"间隙区域无黑像素"恒失败.

2. 源码侧验证: 在测试 #1 输入下逐点检查 mask[y,x] — 测试环上 306 个采样点全部 mask=255 (保留), 因此原图黑色像素本就是测试图自身的外黑边, 不是 _redraw_border_on_corner 误涂.

3. 边界改动控制: B1 阶段尝试过在 sector_render.py:354 收紧 d_region 下界 — 实测后失败数从 7 跳到 6 但新增 1 个回归 (test_complex_pattern_with_gaps), 已立即回滚. 当前源码 git diff core/ = 空.

剩余 4 个失败详细分类

诚实声明
本轮 B1 阶段仅完成"测试圆心几何错"的诊断与修复. 以下 4 个失败的真因未在本轮深 trace, 分类基于现有日志与错误信息, 不等于"已确诊". 下一轮应专项处理.
R1
test_border_smoothness
P0 待诊

症状

缺口数 30/30 (100%)
基线 (B1 前) 24/30 (80%)
测试期望 dist=R 圆弧上 95% 像素非白 (gap_ratio < 5%)

实测发现

改后圆心已正确, 但测试图只在图周 50px 画黑边, 圆弧 R=177 远大于 50px → 圆弧扫描点全部落在白底区. 测试图与断言语义不匹配.

真因 (初步) 测试图构造与断言目标错位 — 非代码 bug

下一轮建议

需要重设计测试图: 使 dist=R 圆弧位置确实落在边框色区域. 或调整断言为"边框区域最外层连续性"而非"圆弧路径上有色".

R2
test_complex_pattern_with_gaps
P0 待诊

症状

gap_is_correct False (间隙区域被填白)
blue_count 10000 (符合预期)
border_gaps_found True (圆弧上有 121 个缺口)

实测发现

输入: 黑50+灰20+红30 边框 + 内部蓝色圆形/绿色矩形/黄色细节. 测试在左下角圆角区域.

本轮未诊断. 本测试属 test_complex_pattern_safety 套件, 走 apply_rounded_corners 路径, B1 圆心修正未触及此测试.

下一轮建议

需 trace _redraw_border_on_corner 在该输入下 (border_layers=[黑51,灰20,红30]) 的 d_region 实际命中模式.

R3
test_multilayer_border_with_mixed_colors
P1 待诊

症状

异常角落 [tl:32, tr:22, bl:22, br:12]
问题模式 非对称 — tl/br 异常像素差异大 (32 vs 12)

实测发现

输入: 蓝41+绿25 多层边框 + 红/蓝填充 + 4 角全部 2cm 圆角.

诊断报告原标 R3 = #2, 但 B1 圆心修正后该测试仍失败, 说明存在圆心几何以外的根因 (可能为低对比度下 sector_render 的 match_filter 误判).

下一轮建议

需 trace match_filter / classify_gap_layers 在低对比输入下的判定逻辑.

下一轮建议 (R1-R4 专项)

R1 优先 (test_border_smoothness)

唯一已被初诊为"非代码 bug"的项目, 但失败数从 80% 上升到 100% 仍属回归. 建议重写测试图, 确保圆弧路径上确实有边框色 (例如: 图周 200px 宽边框, 远大于 R=177).

R2-R4 优先级
  • R2 (test_complex_pattern_with_gaps): 走 apply_rounded_corners, 与 R3/R4 同源问题可能在不同输入下的表现. 建议先 trace 此项再交叉对照.
  • R3 (test_multilayer_border_with_mixed_colors): 4 角非对称, 涉及 corner_protect_map 的 per-corner 决策, 建议 trace _corner_sector_has_content 在 4 角调用上的返回值差异.
  • R4 (test_extreme_colors_and_anti_aliasing): 单角 br=2.5cm, 灰边+白间隙+深灰内容. 怀疑 match_filter 在 RGB 极值附近的色差阈值 (COLOR_DIST_THRESHOLD=15) 设定不当.
