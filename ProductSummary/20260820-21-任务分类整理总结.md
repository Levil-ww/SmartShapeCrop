## 六、关键决策与原则汇总

### 6.1 草图识别核心原则
1. **OCR优先信任**：标注数值代表设计意图，几何值计算受内框检测和像素距离影响不可靠
2. **几何约束优先**：8个字段存在严格几何约束（外框=内框+边距和），是识别纠错的最可靠机制
3. **方向标签降级**：Tesseract对手写中文识别率低，通过几何位置判断方向作为降级机制
4. **独立扫描优先**：Step4方向标签识别必须优先使用独立扫描模式，全局OCR扫描仅作回退
5. **33%硬边带约束**：margin_top/bottom/left/right分别对应画面上下左右33%区域

### 6.2 性能优化原则
1. **不改变功能逻辑**：优化必须在不改变功能逻辑的前提下进行
2. **几何等价性**：所有优化通过像素级一致性验证保证几何等价
3. **回退机制**：EDT替换、几何捷径等提供回退机制保证安全性
4. **优先级分级**：P0（OCR合并、EDT替换）→ P1（外框剪枝、圆角ROI）→ P2（矩形早停、mask复用）
5. **预览优先**：预览用BILINEAR，导出用LANCZOS，质量分级

### 6.3 圆角裁剪核心原则
1. **深色外层保护**：最外层(i=0)深色边框max RGB ≤ 150永不判为间隙
2. **浅色外层判定**：max RGB > 150可通过邻居差异判定为间隙
3. **白点区分**：设计白点（散点式、小规模）与白色扇形伪影（大面积连续）需区分处理
4. **弧外侧检查**：白色扇形伪影检测仅检查弧外侧区域（距离≥半径+边框厚度+5px）
5. **统一逻辑**：间隙层判定统一为classify_gap_layers单一来源
6. **最内层保护**：最内层永不判为间隙（间隙需要两侧边框夹住）

### 6.4 水池设计器渲染原则
1. **执行顺序关键**：保存非白色像素→白色填充→恢复非白色像素→绘制黑色边框线
2. **stretch模式优先**：避免cover模式因方向不匹配裁剪边框
3. **内外区域不同处理**：inner_mask内部纯白，外部保留素材图花纹
4. **模式独立**：compute_inner_corner_radii通过direct参数区分水池模式和普通模式
5. **边框完整性**：使用stretch模式确保四边边框完整保留

### 6.5 历史记录原则
1. **3天保留策略**：保留今天及前2天历史记录
2. **每日上限**：每天上限50条，自动清理过期记录
3. **物理隔离**：两个面板历史记录完全独立存储，避免混乱
4. **source常量**：TARGET_SRC_CROPPER（圆角裁剪工具）、TARGET_SRC_POOL（水池设计器）
