## 2. 核心功能：单边阶梯 L 形挖角

这是 V2.2.3 的旗舰功能，分 6 期完成从可行性分析到全链路落地。

### 2.1 功能说明

传统 L 形挖角在每个角位只能做一级直线切割（一个 CutRect）。阶梯 L 形挖角允许在**同一个角位**做**最多 3 级阶梯切割**，形成阶梯状轮廓，适用于更复杂的印刷裁切场景。

```
标准 L 形（1 级）          阶梯 L 形（3 级示例）
┌──────┐                  ┌──────┐
│      │                  │      │
│   ┌──┘                  │   ┌──┘
│   │                     │   │
│   │                     │ ┌─┘
│   │                     │ │
└───┘                     └─┘
```

### 2.4 数据模型：CutRect

```python
@dataclass
class CutRect:
    anchor: str        # 角位: 'tl', 'tr', 'bl', 'br'
    offset_x_cm: float # 距角位水平偏移
    offset_y_cm: float # 距角位垂直偏移
    w_cm: float        # 切割宽度
    h_cm: float        # 切割高度
```

校验规则（`_validate_l_cut_rects`）：
- 最多 3 级
- 所有尺寸必须为正
- 不得超出画布边界
- 同角位 CutRect 之间不得重叠

## 6. 综合形状可行性分析

V2.2.3 后期（9 月 22-23 日）启动了**综合形状**（中间挖洞 + L 形挖角组合）的可行性分析，产出 V2.0 报告。

### 6.1 三项已拍板决策

| # | 决策项 | 选定方案 |
|---|--------|----------|
| D1 | 外壳 | 新开独立面板 `composite_panel.py` 继承 `LShapePanel` |
| D2 | 洞填充语义 | 洞支持填素材（不止挖空白） |
| D3 | 洞/角组合范围 | 单洞 + 多角（1-4 角），暂不支持多洞+多角 |

### 6.2 目标功能

```
KEEP = Rect(outer) − Σ CutRect(corner, w, h) − Hole(hole_w × hole_h, 带圆角)
```

新增 `mode='rect_lshape_hole'`，需要：
- 新 `build_composite_mask()` 函数
- 19 处 `mode` 分治修改
- 新 `composite_sketch_parser.py`
- 独立面板入口

预计工期：10-16 个工作日（此为 V2.2.4+ 规划）。
