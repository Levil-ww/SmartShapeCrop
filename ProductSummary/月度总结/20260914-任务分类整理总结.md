## 三、模块 1 摘要｜L 形挖角 · 多角扩展

> 完整内容见 `L形挖角设计器/20260914-多角L形挖角（收敛点解除+G1闸口+切边补边越界修复）.md`

### 3.1 可行性分析 V1.0 → V1.1 的估算修正

V1.0 把「草图识别多角化」当成了需要**从零发明算法**的活，列为硬骨头 ② 估 7–10 天。实测复检推翻了这一判断 —— **多挖角的几何数据现有代码早已算出**：凸包差异法算出 2 个连通域、`approxPolyDP` 的 tier2 里躺着 7 个双凹角候选（误差 <0.2cm），只是被三个「单角收敛点」掐成了 1 个。

> **这不是算法问题，是优先级问题。**

| 项目 | V1.0 | V1.1 |
|---|---|---|
| 识别层工作量 | 7–10 天 | **3–5 天** |
| 硬骨头数量 | 2 层 | **1 层**（仅边框补全） |
| 预计总工期 | 3–4 周 | **2.5–3 周** |

### 3.2 三个收敛点解除（`7524f30`）

| 位置 | 收敛形态 | 复检证据 |
|---|---|---|
| `_detect_by_convex_hull:343` | `1 + argmax(areas)` | 连通域**恰好 2 个**（27.5×8.0 / 29.5×12.8） |
| `_collect_approx_candidates:705` | `_tier1 or _tier2 or _tier3` | tier2 里躺着 **7 个**双凹角候选 |
| `:587` | `max(score)` | 按角位分组取最优 |

**修复前输出**：`corner='bl'`, `cut=29.5×12.75cm` —— **静默丢掉右上 28×8，且报 success**。
**新增判据**：「触碰 ≥ 2 条 bbox 边」的**拓扑性质**判据（区分真凹角与文字噪点），替代单纯面积阈值。

### 3.3 G1 结构一致性闸口（`300c3dc`）

`g1_blocked = n_detected != n_consumed` 直接决定 `success`。**测试语义反转**是从「有告警但报成功」变成「不完整就不报成功」的证明：

```python
-            assert res.success, f"应成功（含 G1 告警）: {res.message}"
+            assert not res.success, f"G1 应阻止不完整结果报告成功: {res.message}"
```

### 3.4 切边补边越界修复（`87b3634` / `097e00c`）

像素取证：产品内容上界 y=62，被 15 列纯色覆盖（x=402~416），竖条厚度 15~16px 与缺口下方水平切边**完全吻合** → 同源同层。

**根因：三条件叠加** —— ① `outer_rect = 整个 canvas`；② `cut_h_px = lshape.cut_h + _ir_y` 越过产品顶边；③ `b[0:yc, ...]` 硬编码从 y=0 起铺。

**修法**：新增 `inset_top` / `inset_right` 两个内缩量，**默认 0 使既有行为逐像素不变**：

```python
inset_top   = cut_h_px - lshape.cut_h
inset_right = cut_w_px - lshape.cut_w
```

这两个差值**天然等价于「cut 越过产品内容的那一段」**，四角落一律成立 —— 因此能把七处签名收拢到两个参数。验证：4 角落 × 2 路径 `inset=0` 逐像素一致、`inset>0` 留白改动 **0** 像素。

### 9.1 教训详情：跨文件签名变更不能拆开提交

`bf81daa`（14:54）只收录了 3 个源文件中的 **1 个**：

- 收录了 `core/lshape_border.py`（已调用 `_apply_profile_path(..., inset_top=, inset_right=)`）
- 未收录 `core/lshape_border_route.py` —— 而 HEAD 版 `_apply_profile_path` **并不接受**这两个关键字参数
- **后果**：Profile 路由必然抛 `TypeError` → 被 `image_ops` 外层 `except Exception` **静默吞掉** → 退化成「统一黑框兜底」→ 蔓生花 / 中古雨林类素材补边丢失，**且无任何报错**

复核自洽性（两个命令都应非空）：

```bash
git show HEAD:core/lshape_border_route.py | grep -n "inset_top"
git show HEAD:core/lshape_border.py | grep -n "inset_top=inset_top"
```

**规则**：本项目大量使用 `except Exception` 静默回退，这类错误**不崩只降级，比崩溃更难发现**。
