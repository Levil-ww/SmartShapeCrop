## 二、L 形挖角深度迭代（T1，9.8–9.10）

### 2.1 Profile Route 两轮迭代（9.8）

**第一轮：真实素材校准（蔓生花 / 中古雨林）**

| 项 | 内容 |
|---|---|
| 现象 | 中古雨林完全没有 L 形边框（切边纯白）；蔓生花沿切边补画颜色与原素材有色差 |
| 根因 | 旧 `_classify_profile` "遇到 field 色段即停" → 中古雨林黑描边后 161px 白边距被当 field，结构在描边处截断只剩 1 层；`_MAX_LAYERS=4` 装不下 5 层；`_LINE_MAX_THICK=18` 小于真实细线 24px；`_DARK_LINE_MAX_CHANNEL=170` 卡住真实线色漂移（168~179） |
| 修复 | 重写分类算法：**窗口收集 → 尾裁 field 段（容差 25→35）→ 定界 → 分组 → 让位规则**；层数只由线位置决定，跨边稳定 |
| 验证 | 蔓生花 5 层 `[黑10, 米285, 线25, 点带123, 线25]`；中古雨林 5 层 `[黑10, 白162, 线15, 文字带124, 线14]`；克罗印花 None 让位 V13（现状不变）；**316 passed + 5 skipped** |

**第二轮：用户反馈三问题修复**

| 项 | 内容 |
|---|---|
| 现象 | ① 只需补到"最外内框线"，点带/文字带及其内侧不处理；② 程序实跑仍无 L 形边框（离线样张正确）；③ 庄园秘境出现白线 + 黑边带变细 |
| 端到端真因 | "无效果"实因 `left` 边最外 2px 出血白边未对齐 → 四边层序错位 → 投票把颜色平均成灰糊；庄园秘境 `[6px 出血白] → [117px 粗黑带] → [39px 米底]`，117px 不被 `_LINE_MAX_THICK=32` 判为线 → Profile 判废 → 落到旧路径，算术均值 `(sx+sy)/2` 在 ROTATE_270 下误差 100%+ |
| 四处修复 | ① **锚点对齐**（`_is_anchor_seg` 近黑不限厚，跳过出血边）；② **层深截断到第二条细线**（`_MAX_LAYERS 5→3`）；③ **粗黑带独立成层** + 让位判定外移到路由层 `profile_yields_to_v13`；④ **几何均值 `sqrt(sx*sy)`** 替代算术均值 |
| 验证 | 蔓生花 → `[黑10, 米285, 线25]`；中古雨林 → `[黑10, 白147, 线20]`；庄园秘境 → `[黑116, 米32]`，黑带 114px≈素材 118px；**320 passed + 5 skipped** |

### 2.2 渲染 Bug 定位与修复（9.9 → 9.10）

| 项 | 内容 |
|---|---|
| 现象 | L 形挖角未保持素材边框，色带部分多出 L 形黑边，挖角"没挖干净"，左下角色带残留 |
| 根因 | `lshape_border_route.py:441 _fill_layers_vertical_horizontal`：当某层 `offs[k] >= yc` 时 `y_lo` 回退 0 → 该层从画布顶端画到 yc，**贯穿垂直切边** |

| 闭环 | 9.10 `ee1097b` / `b607e3a` 修复 L 形绘制 + 四角相同逻辑 `total_blacks`；`74122bd` / `75e9724` 修复内边框溢出 |
