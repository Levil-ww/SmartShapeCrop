# 2026年08月18日 水池设计器草图数值识别与方向标签优化

## 概述
用户要求草图识别必须准确提取**所有**数值（外框尺寸、内挖尺寸、上下左右边距），并正确处理带方向标签（上下左右）与无标签双矩形两种场景。本轮聚焦几何OCR搜索区域、边距值选择策略、方向标签合并优先级、可疑值过滤回退四大优化点。

---

## 一、用户需求明确

### 1.1 必须准确识别的数值类型
| 类别 | 示例（图三） | 映射规则 |
|---|---|---|
| 外框尺寸 | 120×58cm | 按宽高位置或方向标签映射 |
| 内挖尺寸 | 57×42cm | 内部矩形宽高 |
| 上边距 | 6 cm | 位置映射或「上」标签对应 |
| 下边距 | 10 cm | 位置映射或「下」标签对应 |
| 左边距 | 14.6 cm | 位置映射或「左」标签对应 |
| 右边距 | 42.4 cm | 位置映射或「右」标签对应 |

### 1.2 两种映射场景
- **场景A（有方向标签）**：标签「上/下/左/右」→ 直接对应 margin_top/bottom/left/right
- **场景B（无标签双矩形）**：根据内外框间隙位置 → 顶部间隙→margin_top，底部间隙→margin_bottom，以此类推

## 二、四项关键优化

### 优化1：几何OCR搜索区域——从固定比例到实际间隙
| 项目 | 旧逻辑 | 新逻辑 |
|---|---|---|
| 搜索区定义 | 外框宽高×固定比例（如0.1-0.3） | **内外框实际间隙区域** |
| 上边距ROI | y: outer_h×0.05 ~ outer_h×0.15 | y: 0 ~ inner_rect.top（真实顶间隙） |
| 右边距ROI | x: outer_w×0.85 ~ outer_w×0.95 | x: inner_rect.right ~ outer_w（真实右间隙） |
| 效果 | 间隙大时漏扫、间隙小时扫到内框 | 精确锁定间隙区，OCR命中↑ |

### 优化2：边距值选择策略——从最小优先到置信度优先
```python
# 旧逻辑：盲目取最小值（易取到OCR噪点/碎片数字）
margin_top = min(all_candidates)

# 新逻辑：取OCR置信度最高的值（稳定数字通常置信度高）
margin_top = sorted(candidates, key=lambda x: -x.confidence)[0].value
```

### 优化3：方向标签合并逻辑——差异过大时保留空间OCR
| 场景 | 方向标签值 | 空间OCR值 | 差异 | 旧结果 | 新结果 |
|---|---|---|---|---|---|
| 右距误读 | 453（标签把53读成453） | 53 | 800%+ | 453（标签优先） | **53**（差异>50%，放弃标签） |
| 上距正确 | 6 | 6.1 | 1.7% | 6 | 6（标签优先） |

**阈值**：标签值 vs 空间OCR差异 > 50% → 保留空间OCR结果（标签可能含百位数误读）

### 优化4：可疑值过滤回退——全是外框候选时返回None
```python
# 旧逻辑：若边距候选全是外框尺寸（如58/120），仍强行取最小→错误
return min(filtered)

# 新逻辑：全是外框值→返回None，交给后续步骤（几何OCR/方向标签）兜底
if all(v in outer_candidates for v in filtered):
    return None  # 让下游模块回填正确值
```
