# 2026年08月29日 水池设计器 多洞矩形裁剪后每洞四边10px黑边框缺失修复

## 概述
T3 GUI启动崩溃修复后，用户进行第一次端到端出图验收，对比单洞输出发现明显缺陷：**多洞模式下，每个矩形裁剪洞的四边缺少完整的10px黑边框**。
- 单洞模式：左右上下四边各10px纯黑边，正确 ✅
- 多洞模式（并排2洞）：仅最上面一条水平线显黑色，两洞其余三边肉眼几乎看不出边框 ❌

共3条子问题。根因：border mask的算法把多洞当成一个"大外包框"做收缩减法。修复：**每洞独立计算 完整矩形 ⊖ 向内收缩10px矩形 的几何差集**得到四边10px带，再合并。新增 pytest `test_92_multi_hole_border_each_hole_four_sides_10px` 做像素级逐洞四边验证。141总测试通过，零回归。

## 问题二：根因定位——外包并集减单收缩内矩形（10:59）

### T2时期临时代码（错误实现）
```python
# 伪代码 T2版
def build_border_mask(holes, canvas, border_px=10):
    # Step 1：取所有洞的并集外包矩形（错误的关键）
    outer_union = rect_union(*[h.rect for h in holes])
    # Step 2：外包整体向内收缩10px
    inner_shrink = outer_union.shrink(border_px)
    # Step 3：外包矩形 - 收缩矩形 = "大框的四边"
    border_mask = draw_rect(outer_union) - draw_rect(inner_shrink)
    return border_mask
```

### 数学图示
```
+---------------------------------------------------+   ← outer_union 整体外包
|  +========+              +========+              |
|  | hole 1  |              | hole 2  |              |
|  +========+              +========+              |
+---------------------------------------------------+

outer_union - shrink(outer_union, 10) 只能得到：
    ┌─────────────────────────────────────────────┐
    │   ★ 顶边（整行10px）★                       │ ← 只有这个正确
    │                                             │
    │ （左右两侧竖边实际在hole1左/hole2右之外）    │ ← 与任何洞不重叠
    │                                             │
    └─────────────────────────────────────────────┘
```
结论：**只有并集整体的4条外边缘得到黑色像素，且这些像素大部分不在真实洞的边界上。各洞的内部分隔边完全没有被描边。**

## 问题三：修复方案——每洞独立几何差集再合并（10:59）

### 正确算法
```python
def build_multi_hole_border_mask(holes, canvas_w, canvas_h, border_px=10):
    """
    多洞10px黑边框：每洞独立算 完整矩形 ⊖ 向内收缩border_px 的几何差集，
    最后取所有洞的并集。保证每个洞的四边各有10px纯黑带。
    """
    full_mask = np.zeros((canvas_h, canvas_w), dtype=bool)

    for hole in holes:
        # ① 该洞的完整矩形像素坐标
        x0, y0, x1, y1 = hole.bbox_px(canvas_w, canvas_h)

        # ② 该洞向内收缩10px后的内矩形
        sx0 = x0 + border_px
        sy0 = y0 + border_px
        sx1 = x1 - border_px
        sy1 = y1 - border_px

        # ③ 安全夹取（防止洞太小收缩后越界；理论上洞的w/h≥2×border_px，否则不画边框）
        if sx1 <= sx0 or sy1 <= sy0:
            continue

        # ④ 几何差集：外矩形 - 内矩形 = 四边各10px的环
        outer = np.zeros((canvas_h, canvas_w), dtype=bool)
        outer[y0:y1, x0:x1] = True
        inner = np.zeros((canvas_h, canvas_w), dtype=bool)
        inner[sy0:sy1, sx0:sx1] = True
        hole_border = outer & (~inner)   # 几何差（边环）

        # ⑤ 合并到总mask
        full_mask |= hole_border

    return full_mask
```

### 关键性质
| 性质 | 说明 |
|---|---|
| **对单洞零改变** | 单洞 `len(holes)=1` 时结果与原单洞算法逐pixel一致 |
| **多洞互不干扰** | 并集用 `|=`；相邻洞即使边界重叠（间距<20px），叠加区域仍为黑色，不产生白缝 |
| **小洞保护** | 洞宽/高不足20px（收缩会夹爆）时跳过该洞，不做负尺寸数组操作 |
| **时间复杂度** | 对8个洞×100万像素画布，整体耗时等价于原单洞的约4倍，仍在LOD渲染≤1s阈值内 |

## 关键决策沉淀
1. **多洞边框的最小语义单元是"每洞"，不是"全局并集"**：描边是洞的属性，必须逐洞计算后再叠加。这一原则对后续圆角洞、L形洞的边框同样适用。
2. **几何差集（outer ⊖ inner）是四边环的数学正确实现**，比"画四条粗线再拼接"更抗收缩越界、抗洞变形、抗宽/高不是整数。
3. **加法分支守门**：入口 if len(holes)>=2，否则原函数不动，确保单洞输出byte-identical（pytest已用哈希断言锁定）。
4. **集成测试必须上像素级断言**：肉眼"看起来有黑边"极易漏掉"某一侧少2px"或"只有顶边"类问题；用合成画布+固定坐标+多点断言是最低成本的稳定性保障。
