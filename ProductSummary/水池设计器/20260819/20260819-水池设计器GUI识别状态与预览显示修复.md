# 2026年08月19日 水池设计器GUI识别状态与预览显示修复

## 概述
用户反馈OCR全局扫描策略修改后，GUI不再显示**草图识别完成状态**和**生成的预览图**。此前用户明确要求：红色矩形框区域内必须展示识别结果，包括「外框尺寸」「内挖尺寸」「上下左右边距」四类参数。排查定位为代码合并冲突导致`_on_sketch_parsed`和`_on_pool_finished_ok`两处回调被覆盖，以及`debug["direction_margins"]`数据存储入口丢失。

---

## 一、问题现象与预期对照

| 界面元素 | 修复前（缺失） | 用户预期 | 位置 |
|---|---|---|---|
| 🔴 识别成功提示 | 无提示，用户无法判断是否完成 | 「识别草图成功 ✓」确认消息 | GUI状态栏或面板顶部 |
| 🔴 外框参数 | 未显示 | **外框 120.0 × 58.0 cm** | 红色矩形框内首行 |
| 🔴 内挖参数 | 未显示 | **内挖 57.0 × 42.0 cm** | 红色矩形框内第二行 |
| 🔴 上下左右边距 | 未显示 | **上 6.0 / 下 10.0 / 左 10.0 / 右 53.0 cm** | 红色矩形框内第三行 |
| 🔴 辅助操作提示 | 未显示 | 「已自动填入【内挖边距】栏，可微调」 | 参数下方提示行 |
| 🖼️  预览图像 | 未生成/未显示 | 解析+生成后自动显示预览图 | 画布右侧或下方预览区 |

## 二、修复的三个关键入口

### 修复1：`_on_sketch_parsed`回调（property_panel.py L889）
负责**解析完成后立即显示识别数据**（不等预览生成），用户需求明确要求「识别状态必须解析后立刻展示，而非等预览生成后」。

```python
def _on_sketch_parsed(self, result):
    """草图解析完成回调：立即显示识别结果（不等图片生成）"""
    if result.success:
        # ---- 1. 格式化识别数据（红色矩形框显示用） ----
        p = result.params
        status_text = (
            f"✅ 识别草图成功\n"
            f"━━━━━━━━━━━━━━━━━━━━\n"
            f"【外框】{p.total_w:.1f} × {p.total_h:.1f} cm\n"
            f"【内挖】{p.inner_w:.1f} × {p.inner_h:.1f} cm\n"
            f"【边距】上 {p.margin_top:.1f} / 下 {p.margin_bottom:.1f} cm\n"
            f"         左 {p.margin_left:.1f} / 右 {p.margin_right:.1f} cm\n"
            f"━━━━━━━━━━━━━━━━━━━━\n"
            f"💡 已自动填入【内挖边距】栏，可微调"
        )
        self.sketch_status_label.setText(status_text)   # 红色框内显示
        self.sketch_status_label.setStyleSheet(         # 红色矩形框样式
            "border: 2px solid #e53935; padding: 8px; "
            "background: #fff8f8; color: #222; "
            "border-radius: 4px;"
        )
        # ---- 2. 同步方向标签识别数据（GUI对比用） ----
        if hasattr(result, 'debug') and 'direction_margins' in result.debug:
            dir_m = result.debug['direction_margins']
            logger.info(f"[GUI] 方向标签识别数据：上={dir_m.get('top')}, "
                        f"下={dir_m.get('bottom')}, 左={dir_m.get('left')}, "
                        f"右={dir_m.get('right')}")
    else:
        # 失败也要显示错误信息（不能静默）
        self.sketch_status_label.setText(f"❌ 识别失败：{result.error_msg}")
```

### 修复2：`_on_pool_finished_ok`回调（property_panel.py L1070）
负责**生成完成后显示预览图** + 二次确认识别数据（防止解析信号丢失时用户仍能看到最终值）。

```python
def _on_pool_finished_ok(self, output_path, result):
    """水池设计器生成完成：加载预览图 + 确认状态显示"""
    # ---- 1. 预览图加载（不能静默失败） ----
    try:
        pixmap = QPixmap(output_path)
        if pixmap.isNull():
            raise ValueError(f"预览图加载失败：{output_path}")
        self.preview_label.setPixmap(pixmap.scaled(
            self.preview_label.size(),
            Qt.KeepAspectRatio,
            Qt.SmoothTransformation
        ))
        logger.info(f"[GUI] 预览图已显示：{output_path}")
    except Exception as e:
        self.sketch_status_label.setText(
            f"⚠️ 生成成功但预览加载失败：{str(e)}\n"
            f"请手动打开输出目录查看：{output_path}"
        )
        logger.error(f"[GUI] 预览加载异常：{e}")

    # ---- 2. 二次确认识别状态（双保险：防止_on_sketch_parsed信号丢失） ----
    if self.sketch_status_label.text().startswith("识别中") or \
       not self.sketch_status_label.text():
        self._on_sketch_parsed(result)  # 补触发一次状态显示
```

### 修复3：`direction_margins`数据存储（sketch_parser.py L6463）
方向标签识别数据必须存入`result.debug["direction_margins"]`，供GUI状态栏显示三列对比（OCR值 vs 方向标签值 vs 几何计算值）。

```python
# sketch_parser.py parse_sketch() 末尾：
debug_info = result.debug if hasattr(result, 'debug') else {}
debug_info['direction_margins'] = {
    'top':    dir_label_top_value,    # 方向标签识别的上距值（可能None）
    'bottom': dir_label_bottom_value, # 方向标签识别的下距值
    'left':   dir_label_left_value,   # 方向标签识别的左距值
    'right':  dir_label_right_value,  # 方向标签识别的右距值
}
debug_info['geometry_margins'] = {    # 几何计算值（用于交叉验证显示）
    'top':    geom_top,
    'bottom': geom_bottom,
    'left':   geom_left,
    'right':  geom_right,
}
result.debug = debug_info
```
