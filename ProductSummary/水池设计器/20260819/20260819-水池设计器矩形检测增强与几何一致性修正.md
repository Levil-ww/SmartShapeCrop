# 2026年08月19日 水池设计器矩形检测增强与几何一致性修正

## 概述
针对两张草图（234×60cm、133×60.5cm）出现的极端识别错误，定位根因为**嵌套矩形检测未过滤极小面积伪内框**（面积仅占外框0.68%），导致后续OCR区域分类与几何计算全面偏离。实施5项增强：嵌套矩形面积过滤器、OCR区域集中度日志、几何一致性强制修正（>5%覆盖）、4种二值掩码策略、内框估计回退机制。

---

## 一、问题诊断

### 1.1 错误案例

| 案例 | 现象 | 根因 |
|---|---|---|
| **234×60cm草图** | 仅左边距36正确，其余7字段全错 | 嵌套矩形检测出**极小伪内框**（面积0.68%外框）→ OCR值全被分类到内框→几何反推全面错误 |
| **133×60.5cm草图** | 仅上边距6、右边距42.4正确，其余6字段错误 | 同上，伪内框导致OCR池分类混乱；且所有OCR值集中于单一区域，无法有效分配 |

### 1.2 OCR区域集中现象
```
理想分布：     实际分布（伪内框出现后）：
上  ┌──────┐   上  ┌──────┐
    │外框值 │       │ █████ │ ← 所有值挤在
左  │内框值 │ 右    │ █████ │   伪内框附近
    │边距值 │       │ █████ │   无法区分
下  └──────┘   下  └──────┘
   4区域分散        1区域集中（集中度>80%）
```

## 二、5项增强方案

### 增强1：嵌套矩形面积过滤器（核心修复）
```python
MIN_INNER_AREA_RATIO = 0.03   # 内框面积 ≥ 外框3%
MAX_INNER_AREA_RATIO = 0.97   # 内框面积 ≤ 外框97%

def _filter_nested_rectangles(outer_rect, inner_candidates):
    outer_area = outer_rect.w * outer_rect.h
    valid = []
    for cand in inner_candidates:
        ratio = (cand.w * cand.h) / outer_area
        if MIN_INNER_AREA_RATIO ≤ ratio ≤ MAX_INNER_AREA_RATIO:
            valid.append(cand)
        else:
            logger.warning(f"过滤伪内框：面积占比{ratio:.2%}，超出3%-97%范围")
    return valid
```

**效果**：0.68%面积的伪内框被直接过滤，系统回退到几何估计或次优候选。

### 增强2：OCR区域集中度警告日志
```python
def _check_ocr_region_concentration(ocr_hits):
    region_counts = Counter(hit.region for hit in ocr_hits)
    total = len(ocr_hits)
    max_region, max_count = region_counts.most_common(1)[0]
    if max_count / total > 0.8:
        logger.warning(
            f"OCR区域集中度异常：{max_region}区域占{max_count/total:.1%}，"
            f"可能存在伪内框或识别不全。建议检查矩形检测结果。"
        )
```

### 增强3：几何一致性强制修正（5%阈值覆盖）
```python
# 几何硬约束：inner = outer - margin_sum
def _enforce_geometric_consistency(total_w, total_h, inner_w, inner_h,
                                    margin_top, margin_bottom, margin_left, margin_right):
    expected_inner_w = total_w - margin_left - margin_right
    expected_inner_h = total_h - margin_top - margin_bottom

    diff_w = abs(inner_w - expected_inner_w) / expected_inner_w
    diff_h = abs(inner_h - expected_inner_h) / expected_inner_h

    if diff_w > 0.05:  # 偏差超5% → 强制用几何值覆盖
        inner_w = expected_inner_w
        logger.info(f"几何修正：inner_w {inner_w_old:.1f}→{inner_w:.1f}（偏差{diff_w:.1%}）")
    if diff_h > 0.05:
        inner_h = expected_inner_h
        logger.info(f"几何修正：inner_h {inner_h_old:.1f}→{inner_h:.1f}（偏差{diff_h:.1%}）")
```

### 增强5：内框估计回退（仅检测到1个矩形时）
```python
# 若嵌套矩形检测仅返回外框（无有效内框候选）
# → 在外框内部搜索最大暗色区域作为内框估计
def _estimate_inner_rect_from_dark_region(outer_rect, gray_image):
    roi = gray_image[outer_rect.y:outer_rect.y+outer_rect.h,
                     outer_rect.x:outer_rect.x+outer_rect.w]
    # 阈值化→找最大轮廓→映射回原图坐标
    _, binary = cv2.threshold(roi, 80, 255, cv2.THRESH_BINARY_INV)
    contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    largest = max(contours, key=cv2.contourArea)
    x, y, w, h = cv2.boundingRect(largest)
    return Rect(outer_rect.x + x, outer_rect.y + y, w, h)
```
