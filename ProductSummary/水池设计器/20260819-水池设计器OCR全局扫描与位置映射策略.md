## 一、四重Bug定位

### Bug 1：OCR字符白名单过严→符号混合数字全过滤
```python

# 结果：草图中"£6"、"#53"等带符号的数字→白名单过滤→整数值丢失！
```

**影响**：草图中带装饰符号（£、#、*、-等）的数值全部被白名单剔除，OCR池为空，后续全面降级。

### Bug 2：PILImage 缺失 import→OCR 结果静默丢弃
```python

```

### Bug 3：OCR扫描区域过窄→方向标签附近数字全部漏扫

### Bug 4：外框矩形选择错误→选到全屏边界伪矩形

## 二、新策略：全局OCR + 位置映射

### 2.1 整体流程
```
步骤1：全图OCR扫描（去除白名单）
    ↓ 输出 (text, bbox, confidence) 列表
步骤2：正则提取纯数值（从含符号文本中剥离）
    ↓ 例："£6"→6，"#53"→53，"右:36.5"→36.5
步骤3：按数值物理位置（bbox中心坐标）映射到8字段
    ↓ 顶部区→外框高/内框高/上边距；左侧区→外框宽/内框宽/左边距...
步骤4：边界伪矩形过滤 + 真实外框二次确认
    ↓ 剔除贴近图像边缘且尺寸≈图片尺寸的矩形
步骤5：几何一致性校验 + 可疑值回退
```

### 2.2 关键代码修改

**① 去除白名单 + 正则后置提取数值**

**③ 边界伪矩形过滤**
```python
def _is_boundary_artifact_rect(rect, img_w, img_h):
    """判断矩形是否是图片边界伪矩形"""
    edge_margin = min(img_w, img_h) * 0.02  # 距边<2%图尺寸
    touches_edge = (rect.x < edge_margin or
                    rect.y < edge_margin or
                    rect.x + rect.w > img_w - edge_margin or
                    rect.y + rect.h > img_h - edge_margin)
    size_close_to_image = (rect.w > img_w * 0.95 and rect.h > img_h * 0.95)
    return touches_edge and size_close_to_image
```
