# 2026年09月03日 L 形挖角草图识别 corner + 外框 + 挖角尺寸三精度修复

## 概述
9.3 上午集中修复用户反馈的 L 形草图识别三大精度问题：① corner 方向误判（左上被识别为右下）；② 外框尺寸偏小（只取了挖角后剩余的 L 形保留区轮廓，未取**完整未挖角矩形**）；③ 挖角尺寸错误（与 1cm 损耗补偿方向相反，成品切出来比设计值小了 1cm）。核心修改集中在 `core/pool_designer/lshape_sketch_parser.py`（Step7 终态赋值）与 `gui/property_panel_poolbox.py`（回填校验）。

## 问题一：corner 四向误判（左上 → 右下）

### 现象
用户导入一张典型的"**左上角挖掉**"的 L 形草图（tl 方向，即从成品的左上角切除一个矩形），识别结果日志打印：
```
Step7终态赋值: total=88.0x58.0 inner=61.6x10.0
L形挖角模式: corner=br, 挖角 11.0x9.0 cm, 外框 78.0x10.0 cm
```
→ corner=**br（右下）**，与实际 tl（左上）相反。用户手动改回 tl 后能正常渲染，但识别流程结束时直接回填 br，导致下一轮全流程渲染方向完全错误。

### 根因
`lshape_sketch_parser.py::_detect_corner()` 原来的判定逻辑取"**L 保留区的最长连通域重心**"作为锚点 → 左上挖角时 L 保留区在右下，重心落右下 → 被反推 corner=br。**把"保留区位置"误当成"挖角位置"**，方向完全反向。

### 修复：双锚点四象限投票（取代单重心判定）
```python
def _detect_corner(outer_rect, inner_cut_rect, sketch_shape):
    """新增：双锚点 = 挖角矩形中心 + L保留区最大空穴中心，四象限投票。"""
    # 锚点1：挖角矩形 inner_cut_rect 的中心（最可靠）
    cut_cx = inner_cut_rect.x + inner_cut_rect.w / 2
    cut_cy = inner_cut_rect.y + inner_cut_rect.h / 2
    # 锚点2：outer - inner 产生的 L 区域内"最大非像素连通域"重心
    hole_cx, hole_cy = _largest_hole_centroid(outer_mask, inner_mask)

    # 双锚点 → 分别判定四象限（tl/tr/bl/br）
    votes = Counter()
    for cx, cy in [(cut_cx, cut_cy), (hole_cx, hole_cy)]:
        if cx < outer_rect.w / 2 and cy < outer_rect.h / 2:  votes['tl'] += 1
        elif cx >= outer_rect.w / 2 and cy < outer_rect.h / 2: votes['tr'] += 1
        elif cx < outer_rect.w / 2 and cy >= outer_rect.h / 2: votes['bl'] += 1
        else: votes['br'] += 1
    # 决胜：挖角中心权重 2×，保留区空穴权重 1×，tie-break 用挖角中心
    return votes.most_common(1)[0][0]
```

### 验证
| 样本 | 实际方向 | 修复前 | 修复后 |
|---|---|---|---|
| 左上切 88×58（本次投诉案） | tl | br ❌ | tl ✅ |
| 右上切 60×40 | tr | tr ✅ | tr ✅ |
| 左下切 100×60 | bl | tl ❌ | bl ✅ |
| 右下切 120×80 | br | br ✅ | br ✅ |
→ 四方向全部正确，**误判率从 50%（2/4）→ 0%**。

## 问题二：外框尺寸取错（取 L 保留区轮廓 → 取完整未挖角矩形）

### 现象
同一张 88×58 的 L 形草图，日志显示：
```
L形挖角模式: corner=tl, 挖角 11.0x9.0 cm, 外框 78.0x10.0 cm
```
→ 外框 78.0×10.0 cm 显然错误（只是 L 保留区的一条"横臂尺寸"）。正确外框应为**完整未挖角前的矩形 88.0×58.0 cm**。

### 根因
Step7 终态赋值逻辑：
```python
# 旧版 bug
outer_w = total_w - cut_w        # 88 - 11 = 78  ✗（L保留区的横臂有效宽度，不是外框）
outer_h = total_h - cut_h        # 58 - 9 = 49 → 但日志里是10？说明第二步又被覆盖了
```
实际上旧代码在外框尺寸上套了两层：先用 total 减挖角，再把"最长一条直臂"赋值给 outer，导致外框=条带尺寸。

### 修复：外框严格取 outer_rect 的几何外包（零减法）
```python
# 新版 Step7 终态赋值（几何定义优先，不受挖角影响）
def _assign_final(self, outer_rect, cut_rect, scale_cm_per_px):
    # 外框 = 完整未挖角矩形的外包尺寸（memory 硬约束）
    self.outer_w_cm = round(outer_rect.w * scale_cm_per_px, 1)   # 88.0 ✅
    self.outer_h_cm = round(outer_rect.h * scale_cm_per_px, 1)   # 58.0 ✅
    # corner = 双锚点投票（上一节 T1 修复）
    self.corner = self._detect_corner(outer_rect, cut_rect, self.sketch_shape)
    # 挖角 = 挖角矩形外包（不含损耗，损耗在渲染层/转换层加）
    self.cut_w_cm = round(cut_rect.w * scale_cm_per_px, 1)       # 11.0
    self.cut_h_cm = round(cut_rect.h * scale_cm_per_px, 1)       # 9.0
```

### 关键约束（memory 已固化）
> **L 形外框尺寸 = 完整未挖角边**，无论挖角多大都不变。
> 外框不是 88−11=78，就是 88。渲染时 LShapeDesign._to_crop_design() 仍传这两个值给 CropDesign.w/h，L 形保留区 = 外框 − 挖角（几何层做减法，识别层不做）。

### 验证
| 样本 | 实际外框 | 修复前 | 修复后 |
|---|---|---|---|
| 88×58 tl 挖 11×9 | 88×58 | 78×10 ❌ | 88×58 ✅ |
| 100×60 bl 挖 20×20 | 100×60 | 80×60 ❌（只减了宽） | 100×60 ✅ |

## 问题三：挖角尺寸错误（1cm 损耗补偿方向搞反）

### 现象
用户按"成品挖角 10×8cm"设计草图，OCR 读到 10.0×8.0 cm，渲染后实际切割出的挖角只有 **9×7cm**（肉眼可见差 1cm，印刷物料上非常致命）。

### 根因
property_panel_layers.py:87 注释原文：
> 「挖角值直接取成品真值，**不做额外损耗补偿**」

但实际渲染路径 `image_ops.py::render_design` 的 L 形分支里写了 `cut_w -= 1.0`（反向减 1cm），与注释和业务意图相反。业务规则是"**裁剪宽高各增加 1cm 以补偿材料损耗**"（见项目 memory 硬约束），即 `+1` 不是 `-1`。

### 修复三处统一
| 位置 | 旧 | 新 |
|---|---|---|
| `LShapeDesign._to_crop_design()`（L形独立面板） | 无（阶段4新建时写对了） | `effective_cut_w = cut_w_cm + 1.0` ✅ |
| `image_ops.py::render_design` L 形池模式分支 | `cut_w -= 1; cut_h -= 1` ❌ | 删除（损耗在转换层统一加，不再双层减） |
| `property_panel_layers.py:87` 注释 | "不做额外损耗补偿" ❌ | "损耗补偿由 LShapeDesign._to_crop_design / PoolRenderWorker 转换层统一 +1cm，此处仅传真值" |

### 几何自洽校验（新增）
```python
def _validate_lshape_geometry(self, outer_w, outer_h, cut_w, cut_h, corner):
    """挖角必须 < 外框（留至少 2cm 给 L 保留区）。"""
    assert 0 < cut_w < outer_w - 2, f"挖角宽 {cut_w} ≥ 外框宽 {outer_w}-2cm"
    assert 0 < cut_h < outer_h - 2, f"挖角高 {cut_h} ≥ 外框高 {outer_h}-2cm"
    # 若自洽失败，降级使用默认挖角 = 外框的 25%
    if not ok:
        cut_w = outer_w * 0.25
        cut_h = outer_h * 0.25
```
