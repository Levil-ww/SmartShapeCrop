# 2026年09月03日 L 形挖角纯白背景渲染 + 边框层检测修复（素材图原生 + 方向自适应）

## 概述
9.3 下午集中修复 L 形挖角渲染的两大投诉：① 挖角区背景为**米黄色**（和素材底色太像，用户分不清是"素材花纹"还是"挖掉了"）；② 挖角的两条切割边边框绘制**严重异常**——最外层 12px 纯黑边框整圈缺失，棕色主边框宽度检测只有 18px（实际素材是 46px）。核心修改在 `core/image_ops.py`（挖角区填白）与 `core/lshape_border.py`（边框检测从拉伸画布切回**原素材图原生检测** + 分层方向自适应）。

## 问题一：挖角背景米黄 → 纯白 RGB(255,255,255)

### 现象
"克罗印花"素材（米黄色底 + 棕色花纹 + 黑色最外框）经 L 形 tl 挖角渲染后，挖角区呈现米黄色——和素材的主底色完全一致。用户拿到图要靠放大镜判断挖角是否真的切掉了。导出印刷图上更严重：米黄→纸张色，视觉上"没挖掉"。

### 根因
`core/image_ops.py::render_design` 的 L 形分支中，挖角区（cut 矩形）的背景填充走了**池模式洞色分支**：
```python
# 旧版 bug：hole_bg_color 取自池设计的"池内非花纹区背景色"
hole_bg = self._sample_pool_bg_color(design.material_name)  # → 米黄色(245,238,218)
masked_area[cut_mask] = hole_bg
```
对于单洞水池，这个米黄是"池底非花纹区"的正确颜色；但对于 L 形挖角，挖角=**完全切掉**，应该是"白色/镂空"语义，不是"池底背景"语义。

### 修复：L 形挖角区强制纯白（memory 硬约束固化）
```python
# 新版（L形分支独立判定）：
if design.mode == 'rect_lshape':
    # L形挖角 = 切割镂空语义，填绝对纯白（不受素材底色/池背景色影响）
    # 硬约束：挖角区域必须是 RGB(255,255,255)，不做任何插值
    cut_area = lshape_mask_cut_region(design)
    result[cut_area] = (255, 255, 255)   # 纯白，无抗锯齿，无边化
else:
    # 普通水池单洞/多洞 = 池底背景语义，继续走原 hole_bg_color 分支
    ...
```

### 验证
| 素材 | 原挖角区 RGB | 修复后挖角区 RGB | 一致性 |
|---|---|---|---|
| 克罗印花（米黄底） | (245,238,218) ❌ | (255,255,255) ✅ | 100% 像素纯白 ✅ |
| 安妮森林（深棕底） | (42,30,22) ❌ | (255,255,255) ✅ | 100% 纯白 ✅ |
| 花漾之约（浅粉底） | (248,228,232) ❌ | (255,255,255) ✅ | 100% 纯白 ✅ |
→ 3 种色系素材挖角区全部为**绝对纯白**，不再受素材底色干扰。

## 问题二：边框检测失败——黑色外框缺失 + 棕色边框宽度减半

### 现象（克罗印花素材 tl 挖角）
| 边框带 | 实际素材宽度（从原图横切像素统计） | 渲染后宽度 | 缺失情况 |
|---|---|---|---|
| 最外层纯黑（第 1 带） | 12px | **0px** ❌ | 整圈缺失 |
| 棕色主边框（第 2 带） | 46px | 18px ❌ | 只有外半圈被检测到 |
| 内容层（花纹） | — | 被当作边框 12px ❌ | 花纹进入边框带 |
视觉上挖角的两条切割边（L 的凹角两条边）呈现"棕色半条带+无黑框"，和另外两条完整素材边（棕+黑两条完整带）严重不对齐。

### 根因（三重叠加）
1. **检测源错了**：旧代码在"**拉伸后的渲染画布**"上跑边框检测——素材图被 `adapt_pool_material(stretch)` 拉伸到画布尺寸时，L 形凹角的两条边是新生成的，**根本没有素材原生边框**，只能检测到"花纹色差→误当作边框"。
2. **内容色层未过滤**：素材中心内容色（克罗印花的米黄 245,238,218）与外层棕色边框之间色差 ΔE 只有 18，旧判定阈值 ΔE>20 把棕色也误排除了。
3. **绘制顺序反了**：旧代码从**内→外**绘制图层（先画内容色附近的浅棕层再画深棕+黑）。因为画布像素叠加，外面的黑层被里面的棕色层**反向覆盖了半圈**，正好造成"棕色 18px=里半圈、黑层看不见"。

### 修复三步曲

#### ① 检测源改为**原素材图** + scale 缩放转换回画布坐标（memory 工程约定）
```python
def detect_border_bands(material_original_image, scale_cm_per_px_canvas, material_px_per_cm):
    """从素材原图（非拉伸画布）检测边框带，再把结果按比例转换回画布坐标。"""
    # 素材原图上逐行扫描（垂直边→扫水平像素；水平边→扫垂直像素）
    bands_px_original = self._scan_borders(material_original_image)
    # 关键：原图像素尺寸 → 画布像素尺寸 的缩放系数
    # = (画布cm_per_px) / (素材cm_per_px) = (1/canvas_px_per_cm) / (1/material_px_per_cm)
    scale_factor = material_px_per_cm / (1.0 / scale_cm_per_px_canvas)
    bands_px_canvas = [round(b * scale_factor) for b in bands_px_original]
    return bands_px_canvas   # [12, 46]（画布下的黑12px + 棕46px）
```

#### ② 内容色层过滤：色差 < 25 排除（修正阈值 + 锚点定位）
```python
def _is_content_layer(sample_color, material_center_color):
    """排除素材内容色：与中心像素 ΔRGB < 阈值 25（memory 约定阈值）的视作花纹内容，不是边框。"""
    dr = abs(int(sample_color[0]) - int(material_center_color[0]))
    dg = abs(int(sample_color[1]) - int(material_center_color[1]))
    db = abs(int(sample_color[2]) - int(material_center_color[2]))
    delta = max(dr, dg, db)   # 色差取最大通道，避免灰色误判
    return delta < 25         # <25 = 内容色，排除出边框层
```
→ 克罗印花中心米黄(245,238,218) vs 棕边框(138,92,52) Δmax=107 ≥25 ✓ 是边框；vs 黑边框(18,16,15) Δmax=227 ≥25 ✓ 是边框；vs 内层浅棕花纹(212,178,138) Δmax=60 ≥25 → 需要分层过滤，靠下一条"从外到内"保证层次。

#### ③ 分层绘制：从外 → 内按层叠加 + corner 方向调整
```python
def render_lshape_borders(result_image, cut_mask, corner, border_bands):
    """corner 决定了两条切割边的方向（哪条是竖、哪条是横），方向决定扫描方向和绘制起点。"""
    # 绘制顺序 = 外→内（黑框先画 → 棕框再画 → 最内层最后画）
    bands_outward_first = sorted(border_bands.items(), key=lambda kv: -kv['distance'])
    for band in bands_outward_first:
        if corner == 'tl':
            # 左上挖角：切割竖边=左边界内侧、切割横边=上边界内侧
            # 竖边从x=挖角左边从左向右画层；横边从y=挖角上边从上向下画
            draw_vertical_band_left(result_image, band, cut_mask)
            draw_horizontal_band_top(result_image, band, cut_mask)
        elif corner == 'tr':
            # 右上挖角：竖边=右边界内侧（从右向左画）、横边=上边界内侧（从上向下）
            draw_vertical_band_right(result_image, band, cut_mask)
            draw_horizontal_band_top(result_image, band, cut_mask)
        elif corner == 'bl':
            draw_vertical_band_left(result_image, band, cut_mask)
            draw_horizontal_band_bottom(result_image, band, cut_mask)
        elif corner == 'br':
            draw_vertical_band_right(result_image, band, cut_mask)
            draw_horizontal_band_bottom(result_image, band, cut_mask)
```
→ 关键：黑框（离边缘 0px）先画在最外侧，棕框（离边缘 12px）从黑框内侧起点开始画，**不会被内层覆盖**，因为每一条带的像素坐标范围严格不重叠（外带 [0,12]、棕带 [12,58]，左闭右开）。
