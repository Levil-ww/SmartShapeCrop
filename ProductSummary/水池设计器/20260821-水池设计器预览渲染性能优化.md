# 2026年08月21日 水池设计器-预览渲染性能优化

## 概述

## 四、关键决策与原则

1. **预览优先**：预览用BILINEAR减少0.4-1.5秒渲染时间
2. **质量分级**：preview用BILINEAR，export用LANCZOS
3. **mask复用**：复用inner_mask省去一次mask计算和corner radii计算
4. **导出质量保证**：保存时重新渲染LANCZOS确保导出质量
5. **肉眼差异小**：BILINEAR与LANCZOS在预览时肉眼差异小
