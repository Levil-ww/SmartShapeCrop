## 二、挖洞素材填充失真

### 2.1 症状

水池挖洞后，**洞周围的素材填充出现失真** —— 填充内容与预期不符（颜色/图案/位移偏差）。

### 2.2 定位

改动落在两个文件：

| 文件 | 职责 | 在挖洞链路中的位置 |
|---|---|---|
| `core/image_cropper.py` | 裁剪主流程 | 洞区域的裁剪与合成编排 |
| `core/image_ops.py` | 渲染引擎 | `render_design()` 的洞填充逻辑 |

**「失真」的常见成因**（本项目历史高发）：

| 类型 | 机制 |
|---|---|
| **坐标错位** | 洞的像素坐标与素材采样坐标不一致 → 填充内容整体偏移 |
| **缩放/重采样失真** | LOD 降采样后回填未还原 → 内容模糊或摩尔纹 |
| **填充源错误** | 洞填充读到了错误的图源（原图 vs 已裁剪图）→ 内容不对 |
| **边界未对齐** | 洞边缘采样越界 → 边缘出现拉伸条纹 |

> **注**：本次修复的具体代码差异未在本提交中留下独立说明，如需精确根因，可回溯 `c039c72` 的 `core/image_cropper.py` 与 `core/image_ops.py` 差异，或查看当时的 `scripts/verify_v13_fix.py` 验证脚本（该提交同批修改）。

### 2.3 关联的当日主线

值得注意 —— **9.14 下午的切边补边越界修复**（`87b3634` / `097e00c`）与本次挖洞填充失真**在根因结构上高度相似**：

| 维度 | 挖洞素材填充失真（上午） | 切边补边越界（下午） |
|---|---|---|
| 共同根因 | 采样/绘制的边界未约束到产品内容之内 | 同左 |
| 关键机制 | 洞的像素坐标 vs 素材采样坐标不一致 | `cut_h_px = lshape.cut_h + _ir_y` 把 cut 扩到画布边缘 |
| 修复思路 | 校正填充源与坐标 | 新增 `inset_top` / `inset_right` 内缩量 |

两者都指向同一个工程事实：**本项目的图像合成链路中，「画布坐标」与「产品内容坐标」是两个容易混淆的坐标系**。画出界、填错位这类 bug 十有八九源于此。
