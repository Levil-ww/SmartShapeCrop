# 2026年08月19日 水池设计器内框可靠性检测与几何值过滤

## 概述
针对「某草图标注右边距36.5，但解析结果为87.3」的问题，定位根因为：**OCR本身识别正确（36.5cm），但嵌套矩形检测给出不可靠伪内框（面积仅3.7%外框），基于伪内框计算出的87.3cm几何值覆盖了正确OCR值**。修复方案为：内框可靠性评级、几何值合理性上限过滤、不可靠内框数据忽略三机制联动。

---

## 一、问题复现

### 1.1 数据流追踪
```
标注值：右边距 = 36.5 cm
                │
                ▼
      ┌─────────────────────┐
      │ OCR扫描右边距区域   │ → 正确识别出 36.5（置信92%）✅
      └─────────────────────┘
                │
                ▼ 并行路径竞争
    ┌─────────────────────┐   vs   ┌─────────────────────┐
    │ OCR结果：36.5cm     │        │ 几何计算：87.3cm    │
    │ 来源：右边距ROI OCR │        │ 来源：inner_w几何反推│
    └─────────────────────┘        └─────────────────────┘
                │                           │
                │                           ▼ 根因
                │                伪内框面积占比仅 3.7%
                │                （正常应>20%，<3%不可靠）
                │                           │
                └───────────── 取几何值覆盖OCR值（旧逻辑优先几何）──┘
                                            │
                                            ▼
                                  最终右边距 = 87.3cm ❌ 错误！
```

### 1.2 根因总结
1. **内框检测不判真伪**：只要检测到矩形就当真内框，不评估面积占比、纵横比合理性
2. **几何值无条件信任**：无论几何反推基于的内框多荒谬，默认优先级 > OCR
3. **无数值合理性上限**：87.3cm边距在外框边宽约120cm的框架中占比73%（常识：边距通常<外框50%），却无过滤

---

## 二、修复机制（三层过滤）

### 层1：内框可靠性评级（面积+纵横比双指标）
```python
def _rate_inner_rect_reliability(outer_rect, inner_rect) -> str:
    """返回 'reliable' | 'unreliable' | 'suspicious' """
    outer_area = outer_rect.w * outer_rect.h
    inner_area = inner_rect.w * inner_rect.h
    area_ratio = inner_area / outer_area

    # 指标1：面积占比
    if area_ratio < 0.05:
        return 'unreliable'   # <5% → 极小伪内框，直接判不可靠
    if area_ratio < 0.10:
        area_score = 'suspicious'
    else:
        area_score = 'reliable'

    # 指标2：纵横比极端（细长条=伪内框特征）
    aspect = max(inner_rect.w, inner_rect.h) / max(min(inner_rect.w, inner_rect.h), 1)
    if aspect > 15:  # 宽高比>15倍（如 1:16 的细条）
        return 'unreliable'

    return area_score
```

### 层2：几何值合理性过滤（50%外框边上限）
```python
def _is_plausible_geometric_margin(value, outer_side_cm, field_name) -> bool:
    """几何计算出的边距必须≤外框对应边的50%，否则拒绝"""
    threshold = outer_side_cm * 0.50
    if value > threshold:
        logger.warning(
            f"[几何过滤] {field_name}几何值={value:.1f}cm > "
            f"外框边{outer_side_cm:.1f}cm × 50% = {threshold:.1f}cm，"
            f"判定不合理，拒绝该几何值，保留OCR结果。"
        )
        return False
    return True

# 应用：右边距案例
# outer_side = 120cm  →  threshold = 60cm
# 几何值87.3cm > 60cm → 拒绝！保留OCR的36.5cm ✅
```

### 层3：不可靠内框 → 几何计算降级为OCR自洽路径
```python
reliability = _rate_inner_rect_reliability(outer, inner)

if reliability == 'unreliable':
    # 内框不可靠：不基于其做几何反推，改用OCR自洽策略
    # 1) 先填边距4值（纯OCR置信度优先）
    # 2) 再由 outer - margin_sum 反推 inner_w/h
    logger.info(f"[降级] 内框可靠性={reliability}，跳过几何反推，"
                f"改用OCR边距→反推内框")
    inner_w = total_w - margin_left_ocr - margin_right_ocr
    inner_h = total_h - margin_top_ocr  - margin_bottom_ocr
else:
    # 内框可靠：正常几何约束路径
    normal_geometry_pipeline(...)
```
