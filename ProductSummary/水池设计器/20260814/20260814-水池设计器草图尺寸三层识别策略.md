# 2026年08月14日 水池设计器草图尺寸三层识别策略

## 概述
用户需求：对上传的3张草图（共4张，第1张混乱需跳过）实现**自动尺寸识别**，提取8项关键数值（外宽/外高、内宽/内高、上下左右边距）并自动回填GUI中对应的内挖边距输入框。实现方案采用三层递进策略（L1→L2→L3），每层失败则回退下一层。

---

## L1：复杂度评估 — 混乱草图自动跳过

### 目标
识别"涂鸦型/字迹密集/多矩形嵌套不可解"的草图，直接标记为跳过，避免输出误导数值。

### 实现（sketch_parser.py）
输入灰度图像后，计算以下指标，**任一触发则判定为混乱**：
| 指标 | 阈值 | 说明 |
|------|------|------|
| Canny边缘密度 | >15% | 边缘点占比过高，画面内容过杂 |
| 连通组件数量 | >200个 | 大量细碎线条/字迹 |
| 最大矩形面积占比 | <10% | 无显著大矩形（找不到外框） |
| 长宽比偏离极值 | >5:1 或 <1:5 | 草图非标准A4/A3比例（可能非图纸） |

### 输出
- 混乱 → 返回 `None` + UI提示"草图过于复杂，请手动输入尺寸"。
- 可解析 → 进入L2。

---

## L2：几何检测 — 嵌套矩形分离

### 目标
从草图中分离出**外框矩形**（整体纸张大小）与**内框矩形**（中间挖空区），并计算对应像素尺寸。

### 实现（sketch_parser.py 基于 OpenCV connectedComponentsWithStats）
1. **二值化 + 形态学闭运算**：填补字迹断线，使外框/内框的四条边连通为整体。
2. **连通组件分析**：
   - 提取面积 Top-5 的连通组件（排除噪声）。
   - 按外接矩形面积从大到小排序。
   - 最大的 → 判定为外框矩形（outer_rect = {x, y, w, h}_px）。
   - 第二大且完全包含于外框内的 → 判定为内框矩形（inner_rect = {x, y, w, h}_px）。
3. **边距几何计算**：
   - top_margin_px = inner.y − outer.y
   - bottom_margin_px = (outer.y + outer.h) − (inner.y + inner.h)
   - left_margin_px = inner.x − outer.x
   - right_margin_px = (outer.x + outer.w) − (inner.x + inner.w)
4. **物理尺寸比例换算**：
   - 若草图含A4/A3标注或DPI元数据，按比例换算为cm（1cm≈96dpi/2.54≈37.8px）。
   - 否则输出像素相对值，留待L3 OCR校准。

### 降级路径
- 找不到外框 → 直接进入L3尝试纯OCR。
- 找不到内框 → 外框保留，内框与边距留空，L3尝试OCR填充。

---

## L3：OCR 标注数字读取（Tesseract 可选安装增强）

### 目标
读取草图上人工标注的数字（如 "60.5"、"133.0"、"14.6"、"42.4" 等），结合位置映射至8个字段中。

### 实现（sketch_parser.py，Tesseract增强版见同日另一篇总结）
1. **全图OCR**：tesseract对整张图做一次识别，拿到所有数字字符串及其bounding box坐标。
2. **位置映射**：
   - 根据数字bbox的几何位置（外框上方/下方/左侧/右侧、内框上方/下方/左侧/右侧）判断其属于哪个字段。
   - 记录 `used_hit_idx` 集合，避免一个OCR命中被多个字段重复占用（见同日OCR修复文档中的全局唯一性检查）。
3. **ROI OCR（兜底）**：对8个字段的理论位置周边（约2cm×1cm区域）单独裁剪做高倍放大OCR，确保小数字不丢失。

### 字段优先级
- 优先填充外框尺寸（全图OCR命中大数字的概率最高）。
- 其次填充内框尺寸。
- 边距字段：若OCR缺失，用"外框-内框"几何关系推导。

## UI回填联动（gui/property_panel.py）

### 触发时机
- 用户上传草图后（`_SketchDropLabel`的pixmap变化事件）。
- 用户修改文件名后（文件名可能含尺寸，需联合草图重新解析）。

### 回填逻辑
```python
parsed = sketch_parser.parse(sketch_path, filename=filename_text)
if parsed is not None:
    self.spin_outer_w.setValue(parsed.outer_w_cm)
    self.spin_outer_h.setValue(parsed.outer_h_cm)
    self.spin_inner_w.setValue(parsed.inner_w_cm)
    self.spin_inner_h.setValue(parsed.inner_h_cm)
    self.spin_margin_top.setValue(parsed.margin_top_cm)
    self.spin_margin_bottom.setValue(parsed.margin_bottom_cm)
    self.spin_margin_left.setValue(parsed.margin_left_cm)
    self.spin_margin_right.setValue(parsed.margin_right_cm)
    # OCR读数字段高亮为淡绿色背景，几何推断字段保持默认
    self._mark_ocr_source(parsed.ocr_source_flags)
```

### 人工可调
- 所有回填值均可手动修改覆盖（OCR仅作推荐，不做锁定）。
- UI旁附"重新识别草图"按钮，方便用户清理后再次解析。

## 经验教训
1. **分层策略是抗干扰的关键**：真实草图质量参差不齐，L1跳过混乱→L2几何保底→L3 OCR校准，三层递进保证"最差也能跳过硬报错"而非输出垃圾数值。
2. **内孔尺寸优先用几何关系算，OCR作校准**：纯依赖OCR容易把外框数字误填到内框字段，几何关系（外框-内框=边距之和）天然提供强约束。
3. **高亮标注OCR来源**：用户能一眼看出哪些值是机器识别的（可能不准），哪些是几何计算的（相对可信），降低信任成本。
