# 2026年08月14日 水池设计器草图交互查看功能

## 概述
优化草图上传后的使用体验：**点击已上传的草图缩略图，可在独立对话框中以大图方式查看，支持缩放、原始尺寸查看等交互**，便于用户核对草图上的标注数字与手绘线条，无需切换到外部图片查看器。

---

## 新增能力一：_SketchDropLabel 可点击化

### 原状态
`_SketchDropLabel`（继承QLabel）仅支持拖拽、点击上传、粘贴上传，上传后缩略图为静态展示，无视觉提示表明可点击查看。

### 修改（gui/property_panel.py）
1. **新增 clicked 信号**：
   ```python
   class _SketchDropLabel(QLabel):
       clicked = pyqtSignal()
   ```
2. **重写 mousePressEvent**：当 label 内已存在 pixmap 时，左键按下 → 发射 `clicked` 信号。
3. **光标交互提示**：
   - 无图状态：默认光标。
   - 有图状态（hover时）：切换为 `Qt.PointingHandCursor`（手型光标），视觉暗示可点击。
4. **边框视觉强化**：有图时缩略图显示实线边框，区别于空状态的虚线框。

## 新增能力二：_SketchViewerDialog 大图查看器

### 功能清单（gui/property_panel.py 内嵌类）
| 功能 | 说明 |
|------|------|
| 自适应显示 | 对话框打开时，按窗口尺寸缩放图片至"恰好容纳"（KeepAspectRatio） |
| 缩放控制 | `+` / `-` 按钮 / Ctrl+滚轮，步长15%，缩放范围 10%~500% |
| 原始尺寸查看 | "1:1"按钮一键回到实际像素尺寸，超出窗口部分可滚动查看 |
| 自适应窗口 | "适应"按钮一键回到恰好容纳状态 |
| 拖动平移 | 大于窗口时，鼠标拖动平移画面（QScrollArea + 内部自定义拖动） |
| 标题栏信息 | 显示文件名 + 实际像素尺寸（如"裁剪图.jpg (2480×3508)"） |
| ESC关闭 | 按ESC键或点击关闭按钮退出 |

### 实现要点
- 使用 **QScrollArea + QLabel（含QPixmap）** 方案：
  - 外层QScrollArea提供滚动条，避免自定义滚动逻辑。
  - 内层QLabel根据缩放比例 `setPixmap(pix.scaled(new_size, ...))` 重新设置图像。
- 缩放状态维护：保存 `self._zoom_factor`（float，默认1.0 = 恰好容纳），避免每次按钮点击重新估算。
- 滚轮事件过滤：在 `eventFilter` 中捕获 Ctrl+Wheel 调整 `_zoom_factor` 并重绘。

## 新增能力三：PropertyPanel 事件串联

### 修改点（gui/property_panel.py）
1. `_build_pool_tab()` 中创建 `_SketchDropLabel` 后，绑定：
   ```python
   self.sketch_label.clicked.connect(self._open_sketch_viewer)
   ```
2. `_open_sketch_viewer()` 方法：
   - 从 `self.sketch_label.pixmap()` / `self._sketch_path` 获取原始图片路径。
   - 优先读取磁盘原图（而非缩略图pixmap），确保大图分辨率。
   - 实例化 `_SketchViewerDialog`，设置模态对话框 `exec_()` 展示。

## 经验教训
1. **缩略图≠原图**：查看大图必须重新读取磁盘原图，否则用户看到的是被QPixmap缩放过的缩略图，数字标注依然模糊。在 `_open_sketch_viewer` 入口处优先使用 `self._sketch_path` 做 `Image.open()`。
2. **手型光标 + 实线边框是双击可发现性的关键**：没有视觉提示时用户几乎不会尝试去"点击缩略图"，此细节极大提升功能发现率。
3. **QScrollArea比自绘拖动更稳定**：自绘平移在大缩放比例下容易出现边界抖动与坐标漂移，QScrollArea经过Qt充分测试，维护成本更低。
