## 一、任务范围

9.15 水池设计器完成椭圆挖洞的基础实现，目标是在现有矩形挖洞能力上增加椭圆/圆形内挖，供水池类裁剪设计直接使用。功能分为两部分：底层椭圆几何与渲染，以及 GUI 参数录入与设计模型传递。

| `613fdfc` | GUI / 数据管线 | 在水池设计器参数面板增加椭圆尺寸参数，支持半径/直径语义，圆形可作为椭圆的等轴特例 |

## 二、实现内容

### 2.1 几何与渲染

- 由外框尺寸和椭圆参数生成椭圆挖洞 mask。
- `image_ops` 适配椭圆保留区、挖洞区和内部边界的渲染路径。
- 参数进入 `CropDesign` 后由 Worker 传递至渲染层，保持水池设计器原有异步生成流程。
- 椭圆与圆形共用同一套椭圆参数结构，圆形仅要求横纵尺寸相等。

### 2.2 参数面板

- 增加椭圆横向、纵向尺寸输入。
- 明确半径/直径的参数表达，避免 UI 数值与 mask 实际尺寸不一致。
- 更新设计模型字段和参数校验，保证尺寸为正并能正确传递到渲染入口。
