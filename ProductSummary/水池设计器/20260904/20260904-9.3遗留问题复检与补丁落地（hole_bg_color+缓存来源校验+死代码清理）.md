## 关键工程教训（复用）

1. **补丁必须用 `git diff --no-index a b` 生成**，不要手写 diff。注意 `--no-index a b` 会产生 `a/a/xxx` 双前缀，需正则收敛回 `a/xxx` 才能 `git apply -p1`。
2. **项目内换行符混用**：`image_cropper.py`、`image_cropper_mask.py`、`test_pool_lshape_flow.py` 是 CRLF；`image_ops.py`、`geometry.py`、`property_panel_workers.py` 是 LF。改文件时必须逐文件保持原换行符，否则 patch 会显示全文件重排。
3. **验证补丁的正确姿势**：`git worktree add F:/xxx HEAD --detach` → 应用补丁 → 跑测试 → `git worktree remove --force`。比复制整个项目快，且完全不碰主工作区。
4. 跑测试别用 `pytest ... | grep`：管道缓冲会吞掉统计行。正确做法：重定向到文件再 tail。
