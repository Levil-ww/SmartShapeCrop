## 一、用户反馈 Bug 修复

### 1. 水池设计器"两侧黑色背景框"（core/image_ops.py）
- **现象**：`65x115CM` 裁剪素材导出图两侧出现宽黑色背景框，`59x117cm` 正常。
- **根因**：等比 contain 后画布左右延展大，`_edge_extend_fill` 用素材最外 1px 边缘像素平铺延展；素材自带黑色外框被拉伸成数百像素黑带。
- **修复**：新增 `_estimate_outer_border` 检测实心外框；延展 > 画布边 5% 且存在外框时，改用内容区中心像素平铺，避开外框与抗锯齿接缝；小延展/无外框保持原"薄边框"行为。
- **验证**：复现脚本黑带 100% → 0%，无外框素材不崩溃，端到端水池渲染黑占比 0%。

### 2. 塞纳时光圆角裁剪"米黄色弧形缺口"（core/corner/sector_render.py）
- **根因**：`is_near_border_color` 遍历的色集含间隙层自身颜色，距离为 0 导致 `force_clear_gap` 永不触发；且旧清除逻辑只匹配"检测到的间隙色"，JPEG/缩放色偏后残留像素连成米黄弧线。
- **修复**：改用实心边框色集判定，使清除分支正确触发；清除逻辑改为保留边框色与背景、清除间隙深度带内其余像素（严格条件才进入，不误伤装饰/图案间隙）。
- **验证**：修复前 1826 个残留像素 → 修复后 0；全套件回归通过。

## 六、L 形挖角草图识别（裁剪有图）

8.28 当日新增的需求闭环：水池设计器"裁剪有图"模式下的 L 形挖角草图自动识别 → UI 回填 → 渲染成型。

**三阶段分工**：
1. **阶段1（解析模块）**：`core/pool_designer/lshape_sketch_parser.py` — 两矩形减法推断法 + 几何驱动标签归属（不依赖字母 OCR），复用 `sketch_parser_vision` 的多尺度 OCR 与健壮文件校验。`core/pool_designer/__init__.py` 导出 `parse_lshape_sketch` 与 `LSketchParseResult`。
2. **阶段2（UI/数据流集成）**：
   - `gui/property_panel_poolbox.py`：接入"识别 L 形草图"按钮。
   - `gui/property_panel_dialogs.py`：新增 `_LShapeConfirmDialog`，允许用户核对/微调识别结果。
   - `gui/property_panel_workers.py`：新增 `_LShapeParseWorker`（线程化 OCR 避免阻塞 UI），扩展 `PoolRenderWorker` 接受 `lshape_params` 构造 `rect_lshape` 设计。
   - `gui/property_panel.py` / `_generate.py`：`_apply_lshape_params` 回填 `cb_mode / cb_lcorner / sp_lw / sp_lh / sp_w / sp_h` 并放宽 cut 范围上限；`_detect_user_margin_edits` 保证手动修改素材匹配不偏移。
3. **阶段3（端到端验证）**：合成与用户 Image4 同参数草图（tr/450×33cm/挖角 100×2cm）跑全链路。
   - 识别：corner=tr、outer=450.0×33.0、cut=100.0×1.94、sc=0.75
   - UI 回填：mode=rect_lshape、corner=tr、canvas=451×34
   - 渲染像素：cut 中心=(250,245,230) 洞色、L 保留区=(117,29,116) 花纹 ✅

**渲染层**：`core/image_ops.py::render_design` 新增 `rect_lshape + is_pool_with_material` 分支——"素材裁成 L 形"语义：L 形区域保留外框素材（不覆盖 inner_fill），cut 角填 `hole_bg_color` 洞色。rect_hole 与非池 rect_lshape 行为不变。
