## 1. 版本概要

V2.2.5 是一个**功能+架构+质量**三驱动版本。核心交付了**综合形状**（中间挖洞 + L 形挖角组合）全链路实现，同时完成了大规模的架构重构（参数协议统一、Builder 提取、草图解析器拆分、GUI 控件抽离），并修复了大量边框渲染与面板交互问题。

### 一句话总结

> 从"L 形挖角 + 水池独立设计"升级到"综合形状一体化"，同时将测试规模从 671 提升至 1900，完成核心模块的架构解耦。

## 3. 核心功能：综合形状（中间挖洞 + L 形挖角）

这是 V2.2.4 的旗舰功能，分 4 阶段完成从设计决策到全链路落地。

### 3.1 功能说明

综合形状将**中间挖洞**（水池设计器能力）与**L 形挖角**（L 形设计器能力）组合为单一设计模式，支持在同一个设计中同时进行中心挖洞和角位挖角。

```
水池设计器（仅挖洞）      L 形设计器（仅挖角）      综合形状（挖洞 + 挖角）
┌──────────┐              ┌──────────┐              ┌──────────┐
│          │              │       ┌──┘              │       ┌──┘
│   ┌──┐   │              │       │                 │    ┌──┘
│   │洞│   │              │       │                 │ ┌──┐
│   └──┘   │              │       │                 │ │洞│
│          │              └───────┘                 │ └──┘
└──────────┘                                        └──────────┘
```
