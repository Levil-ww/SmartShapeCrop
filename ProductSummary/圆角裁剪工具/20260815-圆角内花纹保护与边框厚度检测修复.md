# 2026年08月15日 圆角裁剪工具 内花纹保护与边框厚度检测修复

## 概述
用户报告圆角裁剪工具在设置 5cm 圆角半径时，内层花纹图案（如"中古大花"）被斜切成圆角，且边框出现变薄现象。预期行为：当圆角半径 ≤ 2× 总边框厚度时，仅裁剪外边框区域，内层花纹保持直角。本篇实施边框厚度自动检测 + 边框带并集定义 + 独立 mask 三重修复。

---

## 问题现象
| 圆角半径 | 预期 | 实际（错误） |
|---|---|---|
| 5cm | 仅外边框圆角，内花纹直角 | 内花纹被斜切成圆角 |
| 18cm | 整图圆角（含内花纹） | 边框变薄 |

### 早期错误修复
首次尝试用边框带约束（边框条**交集**）限制裁剪区域，导致圆角处出现**方块白斑**。

---

## 根因分析（3 项）

### 根因 1：边框带定义错误（交集而非并集）
- **错误**：边框带定义为边框条交集（如左上角 = `max(x,y) ≤ T`，即顶条 ∩ 左条）
- **后果**：半径 > 边框厚度时，交集区域无法覆盖完整 L 形边框，产生方块白斑
- **正确**：边框带应为边框条**并集**（如左上角 = 顶条 ∪ 左条，即 `x≤T 或 y≤T`）

### 根因 2：单 mask 同时用于裁剪与边框重绘
- **错误**：裁剪 mask 与边框重绘 mask 共用一个，边框带约束同时限制了重绘范围
- **后果**：圆角处边框重绘不完整，边框变薄
- **正确**：裁剪 mask（边框带限制）与边框重绘有效性 mask（完整扇形覆盖）分离

### 根因 3：角保护逻辑反向
- **错误**：将边框带约束应用于大半径（应整图圆角）而非小半径（应仅边框圆角）
- **后果**：大半径时内花纹区域出现意外直角
- **正确**：边框带约束仅应用于小半径（≤ 2× 总边框厚度）

---

## 修复方案（core/image_cropper.py）

### 1. 边框厚度自动检测
自动计算总边框深度（所有层厚度之和），用于角保护判定：
```python
protect_content = (total_border_thickness > 0) and (max_radius ≤ 2 × total_border_thickness)
```
- `protect_content=True`：仅裁剪外边框区域（L 形边框带），内花纹保持直角
- `protect_content=False`：整图圆角（含内花纹）

### 2. 边框带并集定义
边框带定义为边框条**并集**：
```python
# 左上角边框带 = 顶条 ∪ 左条
border_zone = (y ≤ T) | (x ≤ T)  # 并集，非交集
```

### 3. 双 mask 分离
| mask | 用途 | 覆盖范围 |
|---|---|---|
| 裁剪 mask | 限制圆角裁剪区域 | 边框带（L 形）限制 |
| 边框重绘有效性 mask | 限制边框重绘范围 | 完整扇形覆盖 |

新增 `_build_border_paint_mask` 函数生成独立有效性 mask，确保圆角处边框厚度完整覆盖。

### 4. 圆角半径分档处理
| 半径 | 行为 |
|---|---|
| < 4.0cm | 仅圆角边框区域（1.5cm 深度） |
| ≥ 4.0cm | 圆角所有嵌套层，但 ≤ 2× 边框厚度时仍保留内花纹直角 |

## 经验教训
1. **边框带必须用并集**：交集定义会导致 L 形边框区域不完整，半径 > 边框厚度时产生方块白斑
2. **裁剪与重绘 mask 必须分离**：共用 mask 会导致边框重绘范围被裁剪范围限制，圆角处边框变薄
3. **角保护逻辑方向不能反**：边框带约束仅适用于小半径（保护内花纹），大半径应整图圆角
4. **边框厚度需自动检测**：不能假设固定厚度，需逐层检测累计总厚度用于角保护判定
5. **内花纹保护判定**：`半径 ≤ 2× 总边框厚度` 是保护内花纹直角的黄金判据，超过则整图圆角
