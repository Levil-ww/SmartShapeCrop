## 问题一：remaining变量未定义崩溃（15:17）

### 现象
圆角裁剪运行时抛出`UnboundLocalError: local variable 'remaining' referenced before assignment`。

### 根因
`sector_render.py`中`remaining`变量在条件分支内赋值，当条件不成立时变量未定义即被后续代码引用。

### 修复（sector_render.py）
在条件分支前为`remaining`提供默认初始值，确保所有代码路径下变量均有定义。

### 验证
修复后无崩溃 ✅

## 问题二：间隙残留清扫逻辑重构（15:26）

### 现象
sector_render.py的间隙残留清扫逻辑存在多个瑕疵：并行数组同步脆弱、is_border_pixel隐式依赖、break语句难以维护。

### 根因
原逻辑采用渐进式过滤，维护多个并行数组，同步关系复杂且脆弱：
1. 并行数组（gap_layers + remaining数组）同步困难
2. `is_border_pixel`函数存在隐式依赖，难以独立测试
3. 多层嵌套break语句导致控制流难以追踪

### 修复（sector_render.py）
| 修复项 | 说明 |
|---|---|
| 渐进式过滤→单遍union匹配 | 一次性遍历所有间隙层，使用union操作合并匹配结果 |
| 移除并行数组 | 单遍处理避免数组同步问题 |
| 显式化is_border_pixel依赖 | 将隐式依赖改为显式参数传递 |
| 简化控制流 | 移除多层嵌套break，使用单层循环+条件判断 |

### 验证
56项圆角核心测试通过 ✅

## 问题四：4设计content_protect_mask实现（16:47）

### 现象
4个设计出现不同问题：
| 设计 | 问题 |
|---|---|
| 玛利亚玫瑰 | 内层花纹图案被修改（>5%花纹像素被覆盖） |
| 闲叙青釉 | 角落渲染不正确（蓝色箭头标记处） |
| 复古花丛 | 边框线过粗，与原素材不匹配 |
| 婉卉 | 程序生成的角落出现多余白色区域 |

### 根因
`_redraw_border_on_corner`函数中，边框深度区域内的**所有像素**都被直接绘制为边框色，覆盖了内层花纹图案。

### 修复（sector_render.py `_redraw_border_on_corner`函数）
引入`content_protect_mask`保护内容像素：

```
content_protect_mask 逻辑：
1. 计算每个像素到边框色的颜色距离
2. 计算每个像素到背景色的颜色距离
3. 若距离 > 6（既非边框色也非背景色）→ 标记为内容像素
4. 仅在非内容像素位置绘制边框色，内容像素保持原样
```

### 验证结果
| 设计 | 修复效果 |
|---|---|
| 玛利亚玫瑰 | 花纹保留率>95% ✅ |
| 闲叙青釉 | 残留像素<1% ✅ |
| 复古花丛 | 边框厚度正确8px ✅ |
| 婉卉 | 多余白色区域消除 ✅ |
120项测试通过，无回归 ✅

## 问题五：边框线自动匹配素材图原厚度（17:01）

### 现象
圆角处边框线厚度与素材图原始边框厚度不一致，content_protect_mask保护范围过大导致边框线变细。

### 根因
1. `content_protect_mask`保护范围过大，将部分边框像素也标记为内容像素
2. `_build_border_paint_mask`容差+8px过宽，导致边框绘制范围不准确

### 修复（image_cropper.py + sector_render.py）
| 修复项 | 说明 |
|---|---|
| 容差收紧 | `_build_border_paint_mask`容差从+8px降至+2px |
| 三区域渐进判定 | 精确限制validity_mask覆盖范围，区分边框区/过渡区/内容区 |
| 边框厚度自动匹配 | 检测素材图原始边框厚度，圆角处使用相同厚度绘制 |

### 验证
边框厚度与原素材一致 ✅

## 经验教训
1. **content_protect_mask是内层花纹保护的关键**：通过颜色距离（>6）区分边框像素和内容像素，仅在非内容像素位置绘制边框色，从根本上解决花纹被覆盖问题
2. **V1.0简洁策略优于复杂清扫**：直接绘制+固定带宽策略比复杂颜色残留清扫逻辑更稳定、更易维护
3. **容差收紧需配合三区域判定**：单纯收紧容差会导致边框绘制不完整，需配合三区域（边框/过渡/内容）渐进判定
4. **并行数组是脆弱设计**：渐进式过滤+并行数组同步容易出错，单遍union匹配更可靠
5. **变量初始化不可忽视**：条件分支内的变量赋值必须确保所有路径都有默认值
