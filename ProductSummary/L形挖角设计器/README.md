# ProductSummary/L形挖角设计器/ — L 形挖角功能演进文档库索引

## 目录说明
本目录集中收录「L 形挖角」功能从**架构设计 → 端到端落地 → 代码审计 → 独立面板重构**的完整四阶段演进文档，时间跨度 **2026.08.21 – 2026.09.02**（共 13 天）。

L 形挖角功能是 SmartShapeCrop V2.x 系列最复杂的单体功能，覆盖「草图特征识别 → OCR 数值读取 → 几何计算 → 数据模型 → UI 控件 → Worker 异步化 → 像素级渲染 → 边框带拟合 → 圆角跟随 → 历史记录」共 10 层链路，文档按演进阶段逐阶段沉淀。
