## 一、功能概述

**阶梯型 L 形挖角**：在同一个角位上挖多级台阶（目前支持 1–3 级），是对单角 L 形和多边 L 形的纵向扩展。用户可手动输入或通过草图识别自动生成阶梯参数。

**核心设计思想**：
1. **形状是推导结果，不是存储状态** —— 用 `CutRect(anchor, offset_x, offset_y, w, h)` 统一表达单角/多边/阶梯
2. **旧模型是新模型的严格子集** —— `offset ≡ 0` 时等价于旧 `(corner, cut_w, cut_h)`
3. **不新增 mode/历史源** —— 集成进现有 L 形面板，绕过静默失效硬编码坑

## 二、数据模型层（core/geometry.py）

### 2.1 CutRect 数据类

```python
@dataclass
class CutRect:
    anchor: Literal['tl', 'tr', 'bl', 'br'] = 'tr'   # 锚定角
    offset_x_cm: float = 0.0   # 水平方向内缩偏移
    offset_y_cm: float = 0.0   # 垂直方向内缩偏移
    w_cm: float = 0.0          # 矩形宽
    h_cm: float = 0.0          # 矩形高
```

**设计要点**：
- `offset_x/y_cm` 是挖角矩形靠近锚定角的那一角，相对两条锚定边向内收缩的距离
- 旧 `(corner, cut_w, cut_h)` 等价于 `offset ≡ 0` 的 CutRect
- 单位：厘米（输入层），像素（渲染层由 `l_shapes_px()` 换算）

### 2.2 CropDesign 集成

```python
class CropDesign:
    # 多角 L 形（旧）
    l_cuts_cm: list[dict] = field(default_factory=list)
    # 单边阶梯 L 形（新）；非空时优先于 l_cuts_cm 表达几何
    l_cut_rects: list[CutRect] = field(default_factory=list)
```

**优先级**：`l_cut_rects` > `l_cuts_cm` > `l_corner/l_cut_w/l_cut_h`（单角）

### 2.3 LShape 像素层适配

```python
class LShape:
    cuts: list[dict] = field(default_factory=list)       # 多角（像素，旧）
    cut_rects: list[dict] = field(default_factory=list)  # 阶梯（像素，新）

    def cut_rect_specs(self) -> list[dict]:
        """偏移感知 cut 列表，供 build_lshape_mask 阶梯渲染。"""
        if self.cut_rects:
            return [dict(c) for c in self.cut_rects]
        return [{'corner': ck, 'cut_w': cw, 'cut_h': ch,
                 'offset_x': 0.0, 'offset_y': 0.0}
                for ck, cw, ch in self.cut_specs()]
```

`l_shapes_px()` 把厘米级 `l_cut_rects` 换算为像素级 `cut_rects` dict 列表（含 corner/cut_w/cut_h/offset_x/offset_y）。

## 三、几何约束层（core/geometry.py · _validate_l_cut_rects）

### 3.1 校验规则

| 规则 | 说明 |
|---|---|
| anchor 合法 | 必须 ∈ {tl, tr, bl, br} |
| 同角 ≤ 3 级 | 每角位最多支持 3 级阶梯（上限由 `_stair_max_levels=3` 控制） |
| 正宽高 | w_cm > 0 且 h_cm > 0 |
| 非负偏移 | offset_x_cm ≥ 0 且 offset_y_cm ≥ 0 |
| 不越界 | offset + w ≤ inner_w，offset + h ≤ inner_h（含 0.5cm 余量） |
| 两两不重叠 | 任意两个 CutRect 矩形区域不得相交（AABB 重叠检测） |

### 3.2 与旧约束的关系

- **l_cut_rects 非空时**：旧 `l_cuts_cm` 路径的「同边求和」约束被跳过（`if not self.l_cut_rects:` 守卫）
- **原因**：阶梯是同角逐级内收，求和是语义错误（如 tr(10)+tr(8.5) 求和 18.5 > 边长会误拦）
- **跨角约束**：阶梯场景下由「两两不重叠 + 不越界」替代旧的「同边求和」规则

### 3.3 退化守卫

内矩形边长 ≤ 0 时跳过越界/重叠校验，交给渲染层的 F1 退化守卫处理（与多边 L 形一致）。

## 四、几何渲染层（core/geometry.py · build_lshape_mask）

### 4.1 核心函数：_rect_from_anchor_offset

```python
def _rect_from_anchor_offset(outer_rect, anchor, offset_x, offset_y, w, h) -> RectShape:
    """按「锚定角 + 相对两条锚定边的内缩偏移」计算单级挖角矩形。"""
```

四象限镜像公式（以 tr 为基准）：

| anchor | x 坐标 | y 坐标 |
|---|---|---|
| tl | `outer.x + offset_x` | `outer.y + offset_y` |
| tr | `outer.right - offset_x - cw` | `outer.y + offset_y` |
| bl | `outer.x + offset_x` | `outer.bottom - offset_y - ch` |
| br | `outer.right - offset_x - cw` | `outer.bottom - offset_y - ch` |

钳制：`cw/ch` 钳制到可用宽/高，防止负坐标导致 numpy 负索引静默切错（N1-01 同款钳制）。

### 4.2 build_lshape_mask 改造

**输入兼容**：`cuts` 参数同时支持旧 3 元组 `(corner, cw, ch)` 和新 dict `{corner, cut_w, cut_h, offset_x, offset_y}`。

**算法流程**（5 步）：
1. 填充外轮廓矩形
2. 遍历 valid_cuts，逐一挖掉 cut 区域（`fill_rect_mask(m, cut, other)`）
3. 对 outer_rect 的非 cut 角应用圆角（跳过被挖掉的角）
4. 对每个 cut 的内凹角应用圆角（opposite_map 映射：cut.br → 内凹角在 cut.tl）
5. 无 cut 时退化为纯矩形圆角

**关键点**：
- 每个 CutRect 独立计算内凹角方向（opposite_map 单值查找 → 逐矩形计算）
- 圆角半径统一使用该角位的 `radii[cut_corner]`
- 多级阶梯的每个凹角都有独立圆角

### 4.3 边框层收缩：_shrink_cut_rect

```python
def _shrink_cut_rect(rect: dict, t: float) -> dict:
    return {
        'corner': rect['corner'],
        'offset_x': rect['offset_x'] + t,  # 锚定边内移，offset 增大
        'offset_y': rect['offset_y'] + t,
        'cut_w': max(0.0, rect['cut_w'] - 2 * t),  # 两侧各内缩 t
        'cut_h': max(0.0, rect['cut_h'] - 2 * t),
    }
```

用于边框多层渲染时，每一层边框的 CutRect 等效参数计算。offset 增大 = 挖角矩形离锚定边更远。

### 4.4 统一入口：_build_design_lshape_mask

从 `CropDesign` 提取参数构建 L 形 bool mask，是渲染层的统一入口。支持 `use_outer`（外框/内框）和 `shrink_px`（额外内缩）参数，被边框分层渲染循环调用。

## 五、识别层（services/sketch_parser/lshape_sketch_parser.py）

### 5.1 模式分类

```python
def _classify_pattern(all_corners) -> str:
    """'single_edge_stepped' | 'multi_edge'"""
```

**判定逻辑**（`_stepped_bucket_corner`）：
1. 按 corner 分桶
2. 对 ≥2 个凹点的桶，按 x 排序后检查 y 是否单调（升/降均可，非严格）
3. 存在这样的桶 → 返回该角位名 → 模式为 `single_edge_stepped`
4. 否则 → `multi_edge`

**设计说明**：阶梯相邻凹点沿边方向对角错位（一轴距递增、另一轴距递减），不共线。旧版共线判定对真实阶梯永不命中。改为单调性判定后，由 B4 反拼 IoU 闸口兜底降级。

### 5.2 条带分解：_convert_stepped_to_cut_rects

**核心算法**：以凹点坐标为条带边界，按 tr 系公式换算：

```
S_i = (ox=0, oy=y_{i-1}, w=W−x_i, h=y_i − y_{i-1})
```

即：水平条带纵向堆叠，贴角位纵边。第 i 级条带 = 从第 i-1 个凹点 y 到第 i 个凹点 y 的水平段。

**四象限镜像**：
- tl: x 镜像
- bl: x + y 双镜像  
- br: y 镜像
- offset 以角位自身两边为基准，镜像不变换数值

**输入**：
- `all_corners_geo`: all_corners 列表（含 concave 坐标）
- `corner`: 阶梯桶角位
- `geo`: 几何 dict（outer_w_px / outer_h_px / verts）
- `dims`: 尺寸 dict（outer_w_cm / outer_h_cm）

**输出**：`(cut_rects, iou)`
- `cut_rects`: list[dict]，含 anchor/offset_x_cm/offset_y_cm/w_cm/h_cm
- `iou`: 反拼轮廓与识别轮廓的 IoU；None 表示无轮廓可比对
- `cut_rects is None` 表示无法构成有效条带

### 5.3 B4 闸口：反拼轮廓 IoU

```python
def _compute_staircase_iou(cuts_cm, outer_w_cm, outer_h_cm, contour_pts, pxcm):
```

**用途**：验证条带分解的正确性。用 CutRect 列表反向裁剪外框 bbox 构建理论阶梯多边形，与识别轮廓做 IoU 比对。

**闸口规则**：
- IoU ≥ 0.92 → 确认阶梯，`cuts_cm` 使用 CutRect 格式
- IoU < 0.92 → 降级为多边 L 形（旧格式 cuts_cm，无 offset）
- 条带退化（如 y 双凹点拼不出阶梯）→ 降级为多边 L 形

**debug 字段**：
- `staircase_pattern`: 模式分类结果
- `staircase_corner`: 阶梯桶角位
- `staircase_iou`: IoU 值
- `staircase_downgraded`: 是否因 IoU 不足降级
- `staircase_invalid_strips`: 是否因条带退化降级

### 5.4 主流程集成位置

在 `_resolve_cut_pair` 之后、G1 闸口之前（约第 1931 行）：

```
cuts_cm 初始化为旧多边格式
    ↓
pattern = _classify_pattern(all_corners_geo)
    ↓
if pattern == 'single_edge_stepped' and len(cuts_cm) >= 2:
    cut_rects, best_iou = _convert_stepped_to_cut_rects(...)
    if cut_rects is not None:
        cuts_cm = cut_rects  # 替换为阶梯格式
        if best_iou < 0.92:
            降级回多边格式
    else:
        降级回多边格式
    ↓
G1 闸口（n_detected vs n_consumed）
```

## 六、GUI 层（gui/lshape_panel.py）

### 6.1 双模式切换

L 形面板顶部新增模式选择器：
- **标准 L 形**（4 角平级行，旧 UI）
- **单边阶梯 L 形**（同角位多级，新 UI）

通过 `_set_staircase_mode(enabled)` 切换，显示/隐藏对应的 GroupBox，模式切换时保留第 1 级参数。

### 6.2 阶梯 UI 结构

```
QGroupBox "单边阶梯挖角参数"  [橙色主题 #E67E22]
├── 角位：[右上角▾]
├── 第1级  宽 [10.0] cm  高 [6.5] cm  [+ 追加一级]
├── ↳ 第2级  宽 [8.5] cm  高 [3.5] cm  [+ 追加一级]   ← 缩进 16px
└── (第3级，最多 3 级)
```

**交互细节**：
- `_stair_max_levels = 3`：最多 3 级阶梯
- 第 2 级起左侧有 `↳` 箭头 + 缩进（`margin-left: 16 * level_idx px`）
- 「+ 追加一级」按钮只在末级行显示，达上限时隐藏
- 删除时只能删末级（至少保留 1 级）

### 6.3 步进值 ↔ 条带换算

**用户输入语义**：第 i 级「步进宽 r_i × 落差 d_i」，第 1 级 = 远端第一步。

**正换算（UI → CutRect）**：`get_cut_rects_cm()`
```
条带 i = (offset_x=0, offset_y=Σ_{j<i} d_j, w=Σ_{j≥i} r_j, h=d_i)
```
即 offset_y 累加前级落差，w 为剩余级宽之和，h 为本级落差。

**逆换算（CutRect → UI 回填）**：`set_cut_rects()`
```
r_i = w_i − w_{i+1}（末级 r_N = w_N）
d_i = h_i
按 offset_y 升序排列
```

自动调整子行数（多余删除，不足追加），并自动切换到阶梯模式。

### 6.4 识别回填路径

在 `_apply_sketch_debug_to_lshape_panel` 中：
1. 判断 `is_staircase = debug.get('staircase_pattern') == 'single_edge_stepped'`
2. 是阶梯 → 走 `set_cut_rects(debug['cuts_cm'])` 路径
3. 状态显示：`"单边阶梯挖角：corner=tr，2 级阶梯"`
4. 每级显示 OCR/像素来源标签

### 6.5 参数同步

`_on_staircase_changed()` 更新 `_lshape_params` dict：
```python
{
    'corner': anchor,
    'cut_w_cm': primary_w,       # 第 1 级宽（兼容旧字段）
    'cut_h_cm': primary_h,       # 总落差（兼容旧字段）
    'cuts_cm': [],               # 旧格式清空（不允许同角重复）
    'cut_rects': cut_rects,      # 阶梯几何真值
    'outer_w_cm': ...,
    'outer_h_cm': ...,
}
```

## 八、边框补全（core/lshape_border.py + core/image_ops.py）

### 8.1 核心函数：_draw_staircase_union_layers

```python
def _draw_staircase_union_layers(canvas_arr, cut_rects, layers) -> bool:
    """沿多个同角位 cut 矩形的联合外轮廓补边。"""
```

**算法**（距离变换法）：
1. 归一化 cut_rects 为整数坐标半开区间
2. 在 cut 联合区域附近建立局部 mask（避免全图距离变换，性能优化）
3. 构建 cut union mask（1 = 被挖掉）
4. 对保留区域（retained = cut == 0）做 `cv2.distanceTransform`（DIST_C，3×3）
5. 距离 ≤ 总厚度的区域为补边区
6. 按距离分层（`np.searchsorted`），逐层赋色

**关键特性**：
- 只在联合 cut 区域**外侧**补边，阶梯内部重叠边不会被重复绘制
- 也不会把边框画回挖空区（距离从保留区计算）
- 局部 mask 优化：只在 cut 联合区域 ± total_t 范围内计算，避免印刷级大图全图运算

### 8.2 集成位置

`apply_lshape_border_completion()` 新增 `staircase_cut_rects` 参数，在以下补边入口传入：
- 顶部边框
- 右侧边框  
- 底部边框
- 左侧边框
- 内凹角补边

每个方向使用对应的 cut_rect 联合外轮廓做距离变换补边。

### 8.3 入口：core/image_ops.py

`generate_lshape_border_completion()` 中提取阶梯 CutRect 的绝对坐标，传入边框补全函数。

## 十、兼容性保障

### 10.1 向下兼容

| 旧用法 | 兼容性 |
|---|---|
| `l_corner + l_cut_w + l_cut_h`（单角） | ✅ 完全兼容（CutRect offset=0 的特例） |
| `l_cuts_cm`（多角） | ✅ 完全兼容（优先级低于 l_cut_rects） |
| `build_lshape_mask(cuts=[...])` 旧 3 元组 | ✅ 支持（isinstance 判断分支） |
| `LShape.cut_specs()` | ✅ 阶梯模式返回近似（丢弃 offset），供只需要 3 元组的下游 |

### 10.2 互斥保证

- `l_cut_rects` 非空时，`l_cuts_cm` 必须为空（UI 层和 Worker 层都保证）
- 两套格式共享同一个 `validate` 入口，但走不同校验分支

### 10.3 G1 闸口

G1 不变量（检测凹角数 = 消费数）对阶梯仍然有效（2 个凹角 → 2 条 CutRect），无需改造。B4 IoU 闸口是阶梯的额外校验层。
