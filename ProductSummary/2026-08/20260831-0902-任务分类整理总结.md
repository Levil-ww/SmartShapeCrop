## 十三、关键决策与原则汇总（8.31–9.2 新增）

### 13.1 素材填充核心原则

1. **三源互斥**：环形边框=原图像素（零重绘）、内洞=stretch 素材（不裁剪）、洞色=纯色，三者 mask 互不交叉
2. **V1→V2 渐进叠加**：V1 依赖 `_pool_sketch_original_margins_cm`，V2 无字段依赖、补齐 V1 盲区，两者共存而非替换
3. **cover 模式禁用**：边距变化的内洞填充一律用 stretch，杜绝 cover 裁剪引起的边际重叠

### 13.2 圆角裁剪安全原则

1. **厚度非负**：边框带厚度永远 `max(0, x)`，绝不传负值给 OpenCV
2. **已裁剪图快检**：四角扇形区白色占比 + 灰度方差双条件，避免二次裁剪
3. **文件名批处理唯一性**：批处理模式必须追加序号后缀，宽高按方向顺序

### 13.3 模板匹配原则

1. **方向签名**：W>H vs H>W 为二元特征，横版/竖版视作两个独立匹配空间
2. **双向比例约束**：比例接近必须宽、高各自独立满足，不允许交叉等价
3. **已裁剪图隔离**：圆弧特征存在时直接跳过模板匹配，走用户自定义尺寸

### 13.4 线程与生命周期原则（导出/渲染 Worker 统一）

1. **\_retire\_worker 范式**：取引用 → isRunning 判断 → requestInterruption → wait(timeout) → deleteLater
2. **closeEvent 顺序**：保存 Worker 退役 → 渲染线程 shutdown → 系统退出，顺序不可颠倒
3. **内存显式释放**：大 numpy 数组 Worker finished 后 del + gc.collect()，不可等引用计数

### 13.5 环境治理教训

1. **PyQt5 版本组合**：PyQt5 5.15.11 + PyQt5-Qt5 5.15.2 是官方正确组合（PyPI 上 PyQt5-Qt5 只有 5.15.2 一个版本），非"版本不匹配"
2. **`python-qt5`** **永久黑名单**：非官方包会覆盖写入 PyQt5 DLL，requirements\_clean.txt 已永久排除
3. **损坏 venv 不就地卸载**：`pip uninstall` 损坏包时会清空整个 site-packages（含 pip），直接重建更安全
4. **备份三件套**：修复前 `pip freeze` 快照 + `pip download` 轮子备份 + 干净 requirements 清单，缺一不可
