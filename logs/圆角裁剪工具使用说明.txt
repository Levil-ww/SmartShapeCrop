================================================================
    SmartShapeCrop 圆角裁剪工具 — 使用说明
================================================================

【工具简介】
圆角裁剪工具是 SmartShapeCrop 的核心功能模块，用于将已有成品图
（JPG/PNG/PSD）按目标尺寸等比缩放，并对四角施加圆角裁剪。
支持从中文文件名自动解析尺寸与圆角参数、模板库自动匹配源图、
多层边框自动检测与圆角重绘，导出印刷级 JPG。

启动方式：python main.py → 界面右侧标签页选择「圆角裁剪工具」

----------------------------------------------------------------
二、操作流程（推荐工作流）
----------------------------------------------------------------

步骤 1：设置模板库目录
  - 在「模板库」输入框中输入或浏览选择模板库文件夹路径
  - 路径下方 ▾ 按钮可查看最近打开的历史目录
  - 程序启动时会自动恢复上次使用的模板库目录

步骤 2：输入目标文件名
  - 在「目标文件名」输入框中输入完整的中文文件名
  - 命名格式：{产品名};{方向}{短边}x{长边}cm{圆角描述}
  - 示例：双面格-定制-定制尺寸-简织;竖版55x41cm右下角圆角半径2厘米

步骤 3：自动匹配源图
  - 点击橙色「自动匹配」按钮
  - 程序从模板库中自动查找最佳匹配的源图
  - 匹配成功后自动填充源图路径和所有裁剪参数
  - 首次扫描较慢，后续使用磁盘缓存，速度大幅提升

步骤 4：（可选）自动识别参数
  - 点击蓝色「2. 自动识别尺寸/圆角」按钮
  - 从目标文件名（或源图文件名）解析产品名、尺寸、布局、圆角
  - 尺寸自动加 1cm 切割损耗，圆角自动加 0.5cm 切割损耗
  - 如已通过「自动匹配」填充参数，此步骤可跳过

步骤 5：调整裁剪参数（如有需要）
  - 修改产品名称、布局（竖版/横版）、宽高尺寸
  - 选择裁剪模式和 DPI
  - 调整圆角半径（见下方「圆角设置」说明）

步骤 6：生成预览
  - 点击「生成预览」按钮
  - 裁剪在后台线程执行，界面显示进度提示，不会冻结
  - 完成后左侧画布显示裁剪结果，并弹出尺寸信息

步骤 7：导出 JPG
  - 确认预览效果后点击「导出 JPG」
  - 选择保存路径（默认与源图同目录，文件名自动生成）
  - 导出同样在后台线程执行，完成后弹出成功提示

----------------------------------------------------------------
三、手动选择源图（不用模板库匹配）
----------------------------------------------------------------

如果不使用模板库自动匹配，可直接：
  1. 点击源图路径右侧「浏览…」按钮
  2. 选择 JPG / JPEG / PNG / PSD / PSB 文件
  3. 选中后自动显示源图尺寸、DPI、颜色模式等信息
  4. 手动输入裁剪参数和圆角设置
  5. 也可在「目标文件名」输入文件名后点「自动识别」提取参数

----------------------------------------------------------------
四、裁剪参数详解
----------------------------------------------------------------

1. 产品名称
   - 用于输出文件名的前缀
   - 自动识别时从文件名提取，也可手动修改

2. 布局
   - 竖版：长边为高度（文件名中竖版加前缀）
   - 横版：长边为宽度（文件名中横版不加前缀）

3. 宽 / 高（厘米）
   - 目标成品的宽度和高度
   - 自动识别时已包含 +1cm 切割损耗
   - 手动输入时请注意是否需要加损耗

4. DPI
   - 输出图片的分辨率，默认 150
   - 范围 72~600，印刷建议 150 以上

5. 裁剪模式

   ┌──────────────┬──────────────────────────────────────────┐
   │ 模式          │ 说明                                      │
   ├──────────────┼──────────────────────────────────────────┤
   │ 简单缩放      │ 直接缩放到目标尺寸，不裁剪不留白，              │
   │ （推荐）      │  保持图片完整性                             │
   ├──────────────┼──────────────────────────────────────────┤
   │ 轻度裁剪       │ 优先裁剪，裁剪量过大时自动改为留白             │
   │              │ 最多裁剪设定比例（默认 15%）                  │
   ├──────────────┼──────────────────────────────────────────┤
   │ 智能模式       │ 自动分析源图和目标比例差异，选择最佳方式        │
   ├──────────────┼──────────────────────────────────────────┤
   │ 裁剪填满       │ 裁剪图片填满目标尺寸，可能损失边缘内容          │
   ├──────────────┼──────────────────────────────────────────┤
   │ 留白填充       │ 完整显示图片，四周可能留白                   │
   └──────────────┴──────────────────────────────────────────┘

6. 最大裁剪比例（%）
   - 仅对「轻度裁剪」模式生效
   - 超过此比例时自动从裁剪切换为留白
   - 默认 15%，范围 1%~50%

7. 背景色
   - 圆角裁剪处和留白区域的填充颜色
   - 点击色块打开颜色选择器
   - 默认白色 (255, 255, 255)

----------------------------------------------------------------
五、圆角设置详解
----------------------------------------------------------------

1. 快速设置
   - 输入半径值后点击快捷按钮批量设置：
     · 四角相同：四个角全部设为同一半径
     · 左上+右下：仅设置对角线上的两个角
     · 右上+左下：仅设置另一对对角线上的两个角
     · 左下+右下：仅设置底部两个角

2. 四角独立设置
   - 可分别设置左上角、右上角、左下角、右下角
   - 半径 0 = 直角（不圆角）
   - 单位：厘米，精度 0.01cm，步进 0.5cm
   - 范围：0~50cm

3. 切割损耗说明
   - 自动识别/匹配时，实际裁剪半径 = 文件名标注半径 + 0.5cm
   - 例：文件名"右下角圆角半径2cm" → 实际裁剪 2.5cm
   - 输出文件名仍标注原始值 2cm
   - 手动调整圆角值时不自动加损耗

----------------------------------------------------------------
六、输出文件名预览
----------------------------------------------------------------

1. 自动命名（默认勾选）
   - 根据产品名、尺寸、布局、圆角参数自动生成文件名
   - 格式：{产品名};{方向}{短边}x{长边}cm{圆角描述}.jpg
   - 尺寸使用原始目标尺寸（不含 +1cm 损耗）
   - 圆角使用原始标注半径（不含 +0.5cm 损耗）

2. 手动命名
   - 取消勾选「自动命名」
   - 在「手动命名」输入框中输入自定义文件名

----------------------------------------------------------------
七、文件名命名规范
----------------------------------------------------------------

格式：
  {产品名};{方向}{短边}x{长边}cm{圆角描述}.jpg

规则：
  - 方向：竖版加"竖版"前缀，横版不加
  - 尺寸：短边在前，长边在后，单位 cm
  - 圆角：无圆角时省略

圆角描述支持格式：
  - 四角：4个圆角半径2cm / 四角半径5cm / 四角做2.5cm半径圆弧角
  - 两角：左下角和右下角做3cm半径圆弧角 / 左下角和右下角圆角半径3cm
  - 单角：左下角圆角半径3.1cm / 右下角半径2cm / 左下角是圆角3.1cm半径

示例：
  双面格-定制-定制尺寸-简织;竖版41x55cm右下角圆角半径2cm.jpg
  双面格-定制-定制尺寸-塞纳时光;78.5x128.5cm4个圆角半径4cm.jpg
  双面格-定制-定制尺寸-花漾之约;38.5x186cm左下角和右下角圆角半径5cm.jpg

----------------------------------------------------------------
八、支持的文件格式
----------------------------------------------------------------

  ┌────────┬────────────────────────────────────┐
  │ 格式    │ 说明                               │
  ├────────┼────────────────────────────────────┤
  │ JPG    │ 主要源图格式，RGB 模式                │
  │ JPEG   │ 同 JPG                             │
  │ PNG    │ 带透明通道的图片，自动转 RGB           │
  │ PSD    │ Photoshop 分层文件，自动合成扁平图     │
  │ PSB    │ Photoshop 大文件格式                 │
  └────────┴────────────────────────────────────┘

PSD 文件处理：
  - 自动读取所有可见图层并合成为单张 RGB 图片
  - 自动裁剪透明边距，保留有效内容区域
  - 如 psd-tools 解析失败，回退到 PIL 直接读取嵌入预览

----------------------------------------------------------------
九、大图处理说明
----------------------------------------------------------------

  - 支持处理印刷级大图（最大 2 亿像素，约 14142×14142）
  - 圆角重绘仅处理角区域（ROI 优化），不全图扫描
  - 裁剪/导出在后台 QThread 执行，界面不冻结
  - 处理过程中显示进度提示对话框
  - 处理期间按钮自动防重复点击

----------------------------------------------------------------
十、常见问题
----------------------------------------------------------------

Q: 自动匹配找不到源图？
A: 请检查：
   1. 模板库目录路径是否正确
   2. 模板库中是否有对应花型的图片
   3. 目标文件名中的产品名和尺寸是否与模板匹配
   4. 形状关键词（弧形/圆形/矩形）和方向关键词（横版/竖版）需一致

Q: 预览/导出时提示"请先选择源图"？
A: 需先通过「浏览…」选择源图文件，或通过「自动匹配」匹配到源图。

Q: 圆角裁剪后边框颜色不连续？
A: 程序会自动检测多层边框并在圆角处重绘。如遇异常，
   可尝试调整裁剪模式为「简单缩放（推荐）」。

Q: 导出的图片尺寸与文件名标注不一致？
A: 文件名标注的是成品尺寸，实际裁剪尺寸已包含 +1cm 切割损耗。
   这是正常行为，用于补偿印刷切割误差。

Q: PSD 文件读取失败？
A: 程序会先尝试 psd-tools 分层合成，失败后回退到 PIL 读取嵌入预览。
   如两者均失败，请检查 PSD 文件是否损坏。

Q: 处理大图时界面卡顿？
A: 裁剪和导出已在后台线程执行。如仍感卡顿，
   可降低 DPI 或裁剪后查看日志 logs/smartshapecrop.log 排查。
