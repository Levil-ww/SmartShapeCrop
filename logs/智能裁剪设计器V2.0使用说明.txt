================================================================
    SmartShapeCrop 智能裁剪设计器 V2.0 — 使用说明
================================================================

【版本说明】
V2.0 相比 V1 新增「智能水池设计器」，支持草图识别（OCR + 方向
标签 + 几何自洽三层策略），可从尺寸草图中自动识别外框尺寸、内
挖尺寸、上下左右边距，并一键生成水池裁剪预览。
圆角裁剪工具同步增强：单步扇形切割算法、多层边框保护、内孔
圆角 1:1 映射、内孔 10px 黑色边框线绘制。

【启动方式】
双击 智能裁剪设计器V2.0.exe 即可运行（无需安装 Python 环境，也无需单独安装 Tesseract-OCR）。
首次启动需解压临时文件（含内嵌的 Tesseract OCR 引擎），约 5-15 秒，属正常现象。
单 exe 文件即可分发，无需附带任何外部文件夹或依赖。

【界面布局】
主窗口左侧为预览画布，右侧为标签页，包含两个功能模块：
  - 「圆角裁剪工具」标签：源图裁剪 + 四角圆角处理
  - 「水池设计器」标签：智能水池模式（文件名匹配 + 草图解析）

----------------------------------------------------------------
一、圆角裁剪工具（标签页一）
----------------------------------------------------------------

功能：将已有成品图（JPG/PNG/PSD）按目标尺寸等比缩放，并对四角
施加圆角裁剪。支持从中文文件名自动解析尺寸与圆角参数、模板库
自动匹配源图、多层边框自动检测与圆角重绘，导出印刷级 JPG。

界面从上到下分为 5 个区域 + 底部操作按钮：

  ┌─────────────────────────────┐
  │  1. 选择源图                  │
  │    ├ 模板库目录               │
  │    ├ 目标文件名 + 自动匹配     │
  │    ├ 源图文件路径             │
  │    ├ 源图信息显示             │
  │    └ 自动识别按钮             │
  ├─────────────────────────────┤
  │  3. 裁剪参数                  │
  │    ├ 产品名称 / 布局 / 尺寸     │
  │    ├ DPI / 裁剪模式           │
  │    └ 背景色 / 最大裁剪比例      │
  ├─────────────────────────────┤
  │  4. 圆角设置                  │
  │    ├ 快速设置（四角相同等）     │
  │    └ 四角独立半径输入          │
  ├─────────────────────────────┤
  │  5. 输出文件名预览             │
  │    ├ 自动命名 / 手动命名       │

【推荐工作流】
  步骤 1：设置模板库目录（输入或浏览选择模板库文件夹路径）
  步骤 2：输入目标文件名（格式：{产品名};{方向}{短边}x{长边}cm{圆角描述}）
  步骤 3：点击橙色「自动匹配」按钮，程序自动查找最佳匹配源图
  步骤 4：（可选）点击蓝色「自动识别尺寸/圆角」从文件名解析参数
  步骤 5：调整裁剪参数（产品名、布局、宽高、DPI、裁剪模式、圆角）
  步骤 6：点击「生成预览」，后台线程执行裁剪，完成后画布显示结果
  步骤 7：确认预览后点击「导出 JPG」，选择保存路径即完成

【圆角设置】
  - 快速设置：输入半径值后批量设置（四角相同 / 对角 / 底部两角）
  - 四角独立设置：分别设置左上、右上、左下、右下
  - 半径 0 = 直角；单位厘米，精度 0.01cm，范围 0~50cm
  - 切割损耗：自动识别时实际裁剪半径 = 文件名标注半径 + 0.5cm
    例：文件名"右下角圆角半径2cm" → 实际裁剪 2.5cm
    输出文件名仍标注原始值 2cm

【V2.0 圆角算法增强】
  - 采用单步扇形切割算法（替代旧版两步方挖填充）
  - 右下角圆角使用 180°→270° 屏幕坐标系扇形切割
  - 多层边框保护：圆角半径 ≤ 2× 总边框厚度时，仅裁剪外层边框
    区域（L 形边框带），保留内层花纹为直角
  - 圆角半径 > 2× 总边框厚度时，对全图执行扇形切割
  - 最外层深色边框（max RGB ≤ 150）永不判为间隙层
  - 黑色边框线在圆角处完整保留，无白色/米色弧形缺口

二、智能水池设计器（标签页二）★ V2.0 新增
----------------------------------------------------------------

功能：通过「文件名匹配模板 + 草图解析边距」一键生成水池裁剪
设计。支持上传尺寸草图（手绘标注外框/内框/上下左右边距），
程序自动识别数值并填入【内挖边距】栏，最终生成带内孔的水池
裁剪图。

【界面区域】
  ┌─────────────────────────────────────────┐
  │ 🏊 智能水池模式（文件名匹配 + 草图解析）   │
  │   A) 模板库: [___________] [▾] [选目录]   │
  │   B) 目标文件: [__________] [选文件][清空][▾]│
  │   C) [草图缩略图] [上传草图][清除草图]      │
  │      草图格式示例（红色线标注上下左右边距）   │
  │   D) 挖空方式: [空白/纯色/素材]            │
  │   E) [🔍 匹配模板 → 解析草图 → 生成预览]   │
  │   F) 提示信息: ✅ 识别草图成功...          │
  │   G) 输出文件名: [_________] [同步目标名]   │
  ├─────────────────────────────────────────┤
  │  画布尺寸 (厘米)  │  内挖边距 (厘米)       │
  │  宽/高/DPI       │  上/下/左/右           │
  │                  │  圆角设置（厘米）       │
  ├─────────────────────────────────────────┤
  │  [生成预览]    [导出 JPG]                │
  └─────────────────────────────────────────┘

【推荐工作流】
  步骤 1：设置模板库目录（与圆角裁剪工具共用同一目录）
  步骤 2：输入目标文件名
    格式：{花型名};{宽}x{高}CM
    示例：吸水皮革-定制-裁剪有图-克罗印花;60.5x133CM
    程序自动识别尺寸并回填画布宽高（水池模式下宽高自动
    交换以正确映射竖版/横版方向，画布尺寸已含 +1cm 损耗）
  步骤 3：上传尺寸草图
    - 点击「上传草图…」按钮选择图片，或
    - 直接将图片拖入左侧缩略图框
    - 支持格式：JPG / JPEG / PNG / BMP / TIFF / WEBP
    - 草图要求：用红色线标注外框、内框、上下左右边距即可
    - 可点击缩略图查看大图
  步骤 4：选择挖空方式
    - ✂️ 空白(挖去不留白)：内孔区域透明
    - 🎨 纯色填充：内孔用内部背景色填充
    - 🖼 素材填充：内孔用内部背景图填充
      （素材图模式下保留原始素材边框像素，四条边均可见）
  步骤 5：点击蓝色大按钮「🔍 匹配模板 → 解析草图 → 生成预览」
    程序依次执行：解析文件名 → 匹配模板源图 → 解析草图 →
    构建 CropDesign → 渲染预览。整个过程在后台线程执行，
    界面显示进度提示，不会冻结。
  步骤 6：查看识别状态
    提示信息区会显示识别结果，格式如下：
      ✅ 识别草图成功：
        外框：60.5 × 133.0 cm
        内挖：50.5 × 122.0 cm
        边距：上5.0/下5.0/左5.0/右5.0 cm
        🔤 方向标注: 上5.0/下5.0/左5.0/右5.0 cm
      （已自动填入【内挖边距】栏，可微调）
  步骤 7：（可选）微调参数
    - 在【内挖边距】栏手动调整上下左右边距（上限 200cm）
    - 在【圆角设置】栏调整内孔圆角（1:1 映射面板输入值）
    - 修改后点击「生成预览」重新渲染
  步骤 8：导出 JPG
    - 确认预览后点击「导出 JPG」
    - 输出文件名默认跟随目标文件名，可点击「同步目标名」重置

【草图识别三层策略（V2.0 核心）】
程序对草图数值采用三层识别策略，层层递进保证准确率：

  第 1 层：方向标签识别（优先级最高）
    - 识别草图中"上/下/左/右"中文方向标注
    - 33% 硬边带约束：上(cy≤H×0.33)、下(cy≥H×0.67)、
      左(cx≤W×0.33)、右(cx≥W×0.67)
    - 8 次独立扫描（2 缩放 × 2 语言 × 2 PSM 模式）
    - 识别成功直接赋值到 margin_top/bottom/left/right

  第 2 层：几何 OCR 识别
    - 全图 OCR 扫描 + 位置映射策略
    - 多尺度（1.5-5.0×）、多预处理（原始/OTSU/CLAHE/反色等
      6 种变体）、多 PSM（11/12/6/4/7/8/13 共 7 种）组合
    - 自动计算最优缩放比例（目标字符高约 40px）
    - 数字优先评分：digit_len × 10 + confidence
    - 相邻 Token 合并：合并分裂的多位数字（如 '3'+'6' → '36'）
    - 候选源严格限制：仅采用目标正/反比值 ±10% 内的数值
    - 内框/边距候选集排除外框值，防止混入
    - 物理合理性约束：内框短边 ≥ 最大边距 40%，
      内框长边 > 最小边距 200%

  第 3 层：几何回退
    - 当 OCR 全部失败时，基于检测到的外框/内框矩形几何
      关系计算边距（内框 = 外框 - 边距之和）
    - 嵌套矩形检测含面积过滤（内框面积 3%~97% 外框面积）
    - 二值掩码 4 种变体：Otsu / Canny / 自适应阈值 / 高阈值
    - 仅检测到一个矩形时，在外框内搜索最大暗区作为内框

【草图识别自洽性保护（V2.0 核心）】
  - 8 字段全自洽（sc=1.0）时，强制重算后无条件恢复 OCR 值
  - 跳过 _validate_pair、inner>outer 修正、35%/80% 裁剪等
    破坏性修改步骤
  - 偏差 > 20% 且 OCR 几何不自洽时，按像素比例重算
  - 偏差 > 20% 但 OCR 几何自洽时，仅覆盖外框尺寸，内框/边距
    保留 OCR 值并交给方向矫正
  - 方向矫正同步交换外框宽高和内框宽高，保持几何一致性
  - 目标纵横比与 OCR 相差 > 33%（竖/横版错配）时才交换目标
    尺寸方向
  - 边距对平局决胜引入 _pair_match_score 加权匹配，
    黄金对 (14.6, 42.4) / (6, 10) 优先

【草图识别失败处理】
  - OCR 未识别到任何数值时，自动降级为几何回退
  - 几何回退也失败时，按默认 10% 短边距推断边距
  - 提示信息显示「⚠️ 草图解析未成功：…（可手动在【内挖
    边距】栏输入）」
  - 用户可在【内挖边距】栏手动输入上下左右边距（上限 200cm）

【内孔圆角与边框（V2.0 新增）】
  - 内孔圆角半径 1:1 映射面板输入值（带 min(边/2) 安全帽）
  - 内孔边缘统一 10px 黑色边框线
  - 实现方式：外圆角矩形减内圆角矩形（内矩形向内偏移 10px、
    半径减 10px）的几何差集；几何方法不可用时回退到形态学腐蚀
  - 素材图模式下保留原始素材边框像素，确保四条边均可见
  - 渲染顺序：1) 保存非白素材像素 → 2) 白色填充内孔 →
    3) 恢复素材像素 → 4) 最后绘制 10px 黑色边框线

【诊断截图（V2.0 新增）】
草图识别过程会自动保存 6 张关键区域截图到 logs 目录，便于
排查识别问题：
  - logs/dbg_outer_rect.png  外框区域
  - logs/dbg_inner_rect.png  内框区域
  - logs/dbg_gap_top.png     上边距间隙子图
  - logs/dbg_gap_bottom.png  下边距间隙子图
  - logs/dbg_gap_left.png    左边距间隙子图
  - logs/dbg_gap_right.png   右边距间隙子图

----------------------------------------------------------------

【圆角裁剪工具】
格式：{产品名};{方向}{短边}x{长边}cm{圆角描述}.jpg
  - 方向：竖版加"竖版"前缀，横版不加
  - 尺寸：短边在前，长边在后，单位 cm
  - 圆角：无圆角时省略

圆角描述支持格式：
  - 四角：4个圆角半径2cm / 四角半径5cm / 四角做2.5cm半径圆弧角
  - 两角：左下角和右下角做3cm半径圆弧角 / 左下角和右下角圆角半径3cm
  - 单角：左下角圆角半径3.1cm / 右下角半径2cm / 左下角是圆角3.1cm半径

示例：
  双面格-定制-定制尺寸-简织;竖版41x55cm右下角圆角半径2cm.jpg
  双面格-定制-定制尺寸-塞纳时光;78.5x128.5cm4个圆角半径4cm.jpg
  双面格-定制-定制尺寸-花漾之约;38.5x186cm左下角和右下角圆角半径5cm.jpg

【水池设计器】
格式：{花型名};{宽}x{高}CM
  - 花型名 + 尺寸必须写
  - 宽在前，高在后，单位 CM（大小写均可）
  - 水池模式下画布宽高自动交换映射竖版/横版

示例：
  吸水皮革-定制-裁剪有图-克罗印花;60.5x133CM

五、OCR 环境依赖（V2.0 新增）
----------------------------------------------------------------

水池设计器的草图识别依赖 Tesseract-OCR 引擎：

【单 exe 已内嵌（默认）】
  V2.0 打包脚本（packageV2.0.py）默认把本机 Tesseract-OCR 完整内嵌
  到 exe 内部（通过 PyInstaller --add-data）。运行时自动解压到系统
  临时目录 _MEIPASS/tesseract/，程序通过 PathResolver 自动定位：
  - 用户机器无需单独安装 Tesseract-OCR
  - 无需附带任何外部文件夹或依赖
  - 单 exe 文件即可使用全部草图 OCR 功能

【自动检测顺序】
  PathResolver 按以下顺序查找 Tesseract（找到即停）：
  1. 内嵌版：_MEIPASS/tesseract（onefile 单 exe 模式，优先）
  2. 同级便携版：exe 同目录 tesseract 子目录
  3. Windows 安装路径：C:\Program Files\Tesseract-OCR 等
  4. 用户目录：~/AppData/Local/Programs/Tesseract-OCR
  5. 其他盘符：D:\Tesseract-OCR / E:\ / F:\
  6. 系统 PATH：shutil.which('tesseract')
  7. 环境变量：TESSERACT_PATH 指向 tesseract.exe
  自动设置 TESSDATA_PREFIX 环境变量。

【未内嵌时的降级】
  若打包时未内嵌（加 --no-tesseract 参数）且用户机器也未安装：
  - 程序自动降级，仅跳过 OCR，不影响其他功能
  - 圆角裁剪、几何回退、手动输入边距均可正常使用

【手动安装（仅未内嵌时需要）】
  若收到的是未内嵌 Tesseract 的版本，又想启用 OCR：
  1. 下载地址：https://github.com/UB-Mannheim/tesseract/wiki
  2. 安装时勾选「Chinese (Simplified)」语言包
  3. 默认安装到 C:\Program Files\Tesseract-OCR
  4. 重启本程序即可自动识别

【OCR 小字符识别增强】
  针对草图中单字符小数字（如 '6'）的特殊优化：
  - 3 倍放大处理
  - 6 种 PSM 模式（8/13/7/10/6/11）
  - 3 种预处理方法（原始 / 自适应二值化 / CLAHE 对比增强）
  - 置信度阈值降至 -1，保留高倍率放大后低置信度但正确的小字
  - 全局唯一性检查（差异 < 0.15 跳过），防止单值占据多字段

----------------------------------------------------------------
六、大图处理说明
----------------------------------------------------------------

  - 支持处理印刷级大图（最大 2 亿像素，约 14142×14142）
  - 圆角重绘仅处理角区域（ROI 优化），不全图扫描
  - 草图识别子图增强：截取草图框(outer_rect)子图单独重跑 OCR，
    并对该子图进行 3×3 分块兜底识别
  - 裁剪/导出/草图解析在后台 QThread 执行，界面不冻结
  - 处理过程中显示进度提示对话框
  - 处理期间按钮自动防重复点击

----------------------------------------------------------------
七、常见问题
----------------------------------------------------------------

Q: 自动匹配找不到源图？
A: 请检查：
   1. 模板库目录路径是否正确
   2. 模板库中是否有对应花型的图片
   3. 目标文件名中的产品名和尺寸是否与模板匹配
   4. 形状关键词（弧形/圆形/矩形）和方向关键词（横版/竖版）需一致

Q: 草图识别数值不正确？
A: V2.0 采用三层策略层层递进，若仍识别有误：
   1. 检查草图是否清晰，红色标注线是否完整
   2. 确认已安装 Tesseract-OCR（见第五节）
   3. 查看 logs/dbg_*.png 诊断截图定位识别区域
   4. 可在【内挖边距】栏手动修正上下左右边距
   5. 修正后点击「生成预览」重新渲染

Q: 草图识别提示「未成功」？
A: 程序会自动降级为几何回退或默认 10% 短边距推断。
   提示信息显示「⚠️ 草图解析未成功：…（可手动在【内挖
   边距】栏输入）」，用户可手动输入边距值（上限 200cm）。

Q: 水池设计器画布尺寸与文件名标注不一致？
A: 水池模式下画布尺寸已含 +1cm 切割损耗（裁剪余料用），
   且宽高自动交换以正确映射竖版/横版方向。属正常行为。

Q: 内孔圆角值与面板输入不一致？
A: 内孔圆角采用 1:1 映射（不加损耗），并带 min(边/2)
   安全帽防止圆角过大溢出。如需更小圆角，直接在【圆角
   设置】栏调小数值。

Q: 内孔边框线粗细不一致？
A: 内孔边缘统一 10px 黑色边框线，通过几何差集实现。
   如遇异常，检查是否使用了素材填充模式（该模式下保留
   原始素材边框像素，四条边均可见）。

Q: 圆角裁剪后边框颜色不连续或有白色缺口？
A: V2.0 已修复此问题：
   - 最外层深色边框永不判为间隙层
   - 黑色边框线在圆角处完整保留
   - 如仍遇异常，可尝试调整裁剪模式为「简单缩放（推荐）」

Q: 预览/导出时提示"请先生成预览"？
A: 需先点击「生成预览」按钮渲染设计，再点击「导出 JPG」。

Q: PSD 文件读取失败？
A: 程序会先尝试 psd-tools 分层合成，失败后回退到 PIL 读取
   嵌入预览。如两者均失败，请检查 PSD 文件是否损坏。

Q: 处理大图时界面卡顿？
A: 裁剪/导出/草图解析均在后台线程执行。如仍感卡顿，
   可降低 DPI 或查看日志 logs/smartshapecrop.log 排查。

Q: 程序双击无反应？
A: 在 exe 同目录会生成 crash.log，把该日志发给开发者定位根因。
