# 2026-09-07

## 圆角裁剪只重绘最外层边框

问题：`apply_border_only_corners` 会沿圆弧重绘内层装饰/深色带，导致圆角处出现紧贴黑色外框的深色弧形。

修改（`core/image_cropper_border.py`）：
1. `apply_border_only_corners` 的 Step A 调用 `_redraw_border_on_corner` 时传入 `only_outermost=True`。
2. 为 `_redraw_outer_border_on_corners` 新增 `only_outermost` 参数；当为 True 时只补绘与最外层边框颜色接近的像素，避免把内层颜色带进圆角。
3. `apply_rounded_corners` 保持 `only_outermost=False` 不变，整体圆角仍重绘多层边框。

验证：
- `tests/core/test_image_cropper.py`、`tests/border/test_border_fix.py`、`tests/border/test_complex_pattern_safety.py` 通过。
- `tests/core/test_rounded_corner.py`、`tests/integration/test_final_verification.py` 通过。
- `tests/border/test_gap_fix_verification.py`、`tests/border/test_user_reported_cases.py` 通过。
- 合成样例 `scripts/verify/corner_outermost_demo.py` 显示仅最外层黑边圆角化，内层棕边保持直角。

## 圆角裁剪仅处理外层边框带、内部保持直角

问题：`apply_border_only_corners` 会依据 `_corner_sector_has_content` 自动判断是否启用内容保护；当角外侧扇形被判断为纯色背景时，保护关闭，导致内层矩形框/装饰带也被圆角化，与“仅边框圆角”语义冲突。

修改：
1. `core/image_cropper_border.py`：`apply_border_only_corners` 所有有效圆角统一启用 `protect_content=True`，不再依赖自动判断。
2. `core/image_cropper_mask.py`：
   - 新增 `_angle_in_corner_sector()` 统一处理 0°/360° 绕接，修复 BR/TR 扇区在右边缘的直边边框被误切出白点的问题。
   - 在 `ring_region` 中额外保护弧线内侧 border_zone 内的直边边框像素，避免 0°/90° 接缝处被误切。
3. `tests/border/test_user_reported_cases.py`：更新 `test_xianxu_corner_clean` 以匹配 border_only 新模式（检查弧内侧内容保留、角方块外无内容残留）。

验证：
- 上述全部测试通过（52 个通过，5 个跳过）。
- 合成样例 `scripts/verify/border_only_inner_right_angle_demo.py` 显示外层黑边圆角化、内层咖色边与内部矩形框均保持直角。

## 圆角裁剪：修复白线与内层仍被圆角化

问题：
1. 圆角接缝处出现竖向/横向白色细线（BR/TR 角 0°/360° 绕接处角度判定未包含边界像素）。
2. 大半径（6.5cm）时内层花纹/文字带仍被圆角化，`apply_border_only_corners` 仍使用完整 `border_layers` 构建 mask，导致 border_zone 过宽。

修改：
1. `core/corner/algorithm.py`：新增 `_angle_in_corner_sector()` 统一处理 0°/360° 绕接。
2. `core/image_cropper_mask.py`：移除本地 `_angle_in_corner_sector()`，改为从 `algorithm.py` 导入；`_post_cleanup_gap_regions` 也改用该 helper。
3. `core/corner/sector_render.py`：`_redraw_border_on_corner` 的 `valid_angle` 改用 `_angle_in_corner_sector()`，修复绕接处漏绘白线。
4. `core/image_cropper_border.py`：
   - `_redraw_outer_border_on_corners` 的 `in_angle` 改用 `_angle_in_corner_sector()`。
   - `apply_border_only_corners` 仅用最外层边框层构建 mask / validity_mask / 重绘 / cleanup，`raw_depth` 也仅用最外层厚度，确保内层图案/文字带保持直角。

验证：
- 全量相关测试通过（47 个通过，5 个跳过）。
- 合成样例 `scripts/verify/large_radius_no_inner_round_demo.py`（1200×2100，r=6.5cm）显示：外层黑边圆角化、内层文字带保持直角、四个角无白线。

## 圆角边界白线残留修复

问题：用户反馈 TR/BR/BL 圆角边界仍有 1–2px 白色竖线/横线，TL 正常。根因是 `_build_border_paint_mask` 的角度容差 `tol=1.0` 与 `_redraw_border_on_corner` / `_redraw_outer_border_on_corners` 的 `tol=2.0` 不一致，导致边界像素在 validity_mask 中为 0 却被 redraw 判定覆盖，随后被 `beyond_arc` 误清成背景白色。

修改：`core/image_cropper_mask.py` 中 `_build_border_paint_mask` 的 `paint_region` 使用 `_angle_in_corner_sector(..., tol=2.0)`，与重绘逻辑保持一致的边界容差。

验证：
- 全量相关测试通过（47 个通过，5 个跳过）。
- 合成样例 `scripts/verify/white_line_check_demo.py`（奶油底+60px 黑边+r=6.5cm）四个角放大图无白线。
