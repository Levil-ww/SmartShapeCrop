  （`_retire_worker` 是唯一正确范式）。`main.py:454` closeEvent 只管 2 个。

  无统一缓存 key；`geometry.py:191` 把 `_cached_outer_image` 塞进 CropDesign dataclass 且 clone 共享引用。
  → 这是「素材残留」bug 被修 5+ 次（8.31 三次 + 9.2 两次）的架构级根因。

  还有 detection(877) / image_cropper_mask(1021) / sketch_parser_numbers(983) 等。

### 架构核心矛盾：伪模块化
property_panel 拆成 5 个 mixin、sketch_parser 拆成 6 个子模块，但都是
「物理切开再用 import 私有符号粘回去」（`sketch_parser.py:49-53` 一次 import 9 个 `_` 符号）。
**文件数变多、行数下降，但改动影响半径和拆分前一样**。真模块化需要定义模块间公共契约。
