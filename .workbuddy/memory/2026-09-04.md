### 关键技术要点（下次复用）
1. **补丁必须用 `git diff --no-index a b` 生成，不要手写 diff**。
   注意 `--no-index a b` 会产生 `a/a/xxx` 双前缀，需正则收敛回 `a/xxx` 才能 `git apply -p1`。
2. **项目内换行符混用**：`core/image_cropper.py`、`core/image_cropper_mask.py`、
   `tests/integration/test_pool_lshape_flow.py` 是 **CRLF**；
   `core/image_ops.py`、`core/geometry.py`、`gui/property_panel_workers.py` 是 **LF**。
   改文件时必须逐文件保持原换行符，否则 patch 会显示全文件重排。
3. **验证补丁的正确姿势**：`git worktree add F:/xxx HEAD --detach` → 应用补丁 → 跑测试 →
   `git worktree remove --force`。比复制整个项目快，且完全不碰主工作区。
   worktree 里没有 .venv，直接用主项目的 `.venv/Scripts/python.exe` 跑即可（依赖在 site-packages，与 cwd 无关）。
4. 主项目测试用 `.venv/Scripts/python.exe`（pytest 9.1.1 + PyQt5 齐全）；
   托管版 python 没装 pytest。
5. **跑测试别用 `pytest ... | grep`**：管道缓冲会吞掉统计行，导致误判为"无输出"。
   正确做法：重定向到文件（`> out.txt 2>&1`）再 tail，本次就踩了这个坑，白跑一轮。
