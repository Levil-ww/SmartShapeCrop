## 项目分析报告：SmartShapeCrop（智能形状裁剪设计器 V2.0）

对 D:\SmartShapeCrop 进行了完整代码审查（core/ + gui/ + main.py + 打包 + 测试）。

### 关键发现（证据确凿）
- **真实崩溃（Critical）**：crash.log 记录 `ValueError: x1 must be greater than or equal to x0`，
  链路 `main._on_design_changed → canvas.set_design → _render_lod → render_design → _get_inner_pixel_mask → geometry.fill_rect_mask`(geometry.py:237)。
  inner_rect 退化（x1<x0）时 `d.rectangle` 抛错，预览静默失败。根因：render/圆角入口缺几何合法性守卫（inner_rect 宽高必须>0）。
- **依赖缺失（High）**：requirements.txt 未列 `pytesseract`，干净安装后 OCR 静默失效（README 表格却列了）。
- **解炸弹顺序错误（High）**：sketch_parser 先 `_load_image` 全量解码，后 `validate_sketch_file` 才校验尺寸；该模块从未设 `Image.MAX_IMAGE_PIXELS`。
- **并发共享（High）**：PoolRenderWorker 在子线程写 `design._cached_outer_image` 等字段，canvas/主线程同时渲染同一 CropDesign → 数据竞争。
- **死代码/文档脱节**：`_fill_corner_boundary_pixels`(algorithm.py:198) 无任何调用；`carve_corner_on_mask(inverse=True)` 分支永不触发（geometry.py:299 恒 False）。README 仍声称其运行。
- **simple_resize=非等比拉伸**：image_cropper.py:1657 `src.resize((tw,th))`，宽高比不符即变形，但 UI 标注"推荐/保持图片完整性"。
- **超时形同虚设**：`_PARSE_TIMEOUT_SEC=20`(sketch_parser.py:30) 定义后从未使用，无真实超时。
- **Tesseract 缺失不降级**：packageV2.0.py:387/README 称"自动降级几何估算"，实际返回 success=False。
- **陈旧 .spec**：`智能裁剪设计器.spec` 硬编码 `D:/SmartShapeCrop/...`，换机打包失败；当前 packageV2.0.py 已改用相对路径（良好）。
- **测试污染**：tests/ 下 9 个文件 0 个 test_ 函数（调试脚本混入）。
