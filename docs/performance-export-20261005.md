# 图片导出与目录式分发优化记录（2026-10-05）

本次先优化图片导出，再调整打包方式。业务几何、匹配规则、图片尺寸、DPI、LANCZOS 重采样、JPEG 质量 95、4:4:4 色度采样和 optimize=True 均保持原样。

**修改原因与实现**

初始剖析中，2953×4134（约 12.2MP）基础设计的渲染约 1.9–2.0 秒，而 JPEG 编码约 0.08–0.10 秒。主要开销在掩膜填充和全尺寸数组的分配、复制，因此此次保留编码参数，优化渲染中的内存操作。

| 修改 | 原因 | 结果 |
|---|---|---|
| 纯色边框和 L 形外围直接广播 RGB 颜色 | 原先为每层颜色生成整张 RGB 数组，然后只取其中一部分 | 不再创建这些全画布纯色临时数组；12.2MP 每张约 35MiB（按尺寸计算，非进程内存实测） |
| 内填和图片边框使用 np.asarray 读取 | np.array 会在 PIL 导出像素数据后再复制一份数组 | 只读来源省去一份数组复制；可写画布仍保留独立数组 |
| 用 np.copyto 的掩膜参数完成图像区域复制 | 布尔索引会先提取大批候选 RGB 像素，再写回画布 | 减少大型选中像素数组的分配；羽化颜色及混合公式保持原样 |
| 打包默认改为 onedir，保留显式 --onefile | onefile 每次启动需要释放内嵌依赖 | 依赖常驻分发目录；用户仍通过 EXE 或桌面快捷方式运行 |
| 关闭面板时等待子 QThread 完成取消 | EXE 验收发现：恢复大素材库时立即关闭，预热线程仍在运行而父窗口被销毁，退出码为 0xC0000409 | 当前及已退役子线程均先取消、再等待退出；关闭可能需要等待正在进行的不可中断工作返回，不使用强制终止 |

**导出实测**

基线为 Git 提交 `23a420a8096987eab998d6770963354242c5c54c` 中的 core/image_ops.py。基线与修改版使用同一几何模块、同一环境、相同设计副本，并交替执行先后顺序。每组重复三次，取总耗时中位数。耗时包含完整渲染、JPEG 编码、文件写入及原子替换，未包含保存对话框或人工操作。

环境：Windows，Python 3.13.14，NumPy 2.5.3，Pillow 12.3.0；与构建使用的虚拟环境版本一致。素材为固定随机种子生成的非均匀纹理，尚未用客户实际印刷素材进行测量。

| 样本 | 像素尺寸 | 修改前 | 修改后 | 总耗时缩短 |
|---|---|---:|---:|---:|
| 矩形基础设计 | 2953×4134 | 2.092s | 1.397s | 33.2% |
| 椭圆基础设计 | 2953×4134 | 2.089s | 1.379s | 34.0% |
| L 形基础设计 | 2953×4134 | 2.196s | 1.462s | 33.4% |
| 矩形背景素材 | 1181×1476 | 0.320s | 0.212s | 33.7% |

**分发方式**

默认命令仍使用当前入口，但默认生成目录版：

```powershell
.venv/Scripts/python.exe packaging/packageV2.2.5.py
```

默认产物为 `dist/SmartShapeCropV2.2.5/智能裁剪设计器V2.2.5.exe`，必须随完整目录一起分发，包含 `_internal/`、Qt、PSD 和 Tesseract 资源。中文、英文等已有 OCR 语言文件保留。可以压缩整个目录，用户完整解压后为 EXE 创建桌面快捷方式。

本次构建使用独立的 `build/export_perf_onedir/` 工作目录和本地 PyInstaller 缓存，保留原 V2.2.2/V2.2.3 EXE。PyInstaller 输出成功；继承的完整 Qt 收集配置带有未使用 Qt3D/QML 插件的 DLL 警告，以及 PyQt5.uic.port_v2 Python 2 兼容子模块缺失提示，程序使用 QtWidgets 和 Python 3。EXE 已三次通过主窗口创建、消息响应及正常关闭检查，隐藏启动检查的响应时间为 1.346、0.943、0.772 秒；不是客户机器双击后的可见窗口实测。检查结果见 `diag_output/export_performance/startup.json`。未做旧版与新版同版本、同条件的启动速度对比，不能给出启动提升百分比。

资源验收发现：Tesseract 版本检查成功，但读取中文绝对目录中的语言包时报 `filesystem error: Cannot convert character sequence: Illegal byte sequence`；在同一目录下使用相对 tessdata 路径则可列出四种语言，确认语言文件完整。依照 AGENTS.md 先询问用户，用户已明确同意英文分发目录。默认目录调整为 `SmartShapeCropV2.2.5`，EXE 名称仍保留中文，并重新构建；用户应解压到完整路径不含中文的位置，例如 `C:\Apps\SmartShapeCropV2.2.5`，再创建桌面快捷方式。最终英文目录版已再次通过三次 EXE 启动和正常关闭检查；附带引擎可读取四种语言包，并将数值探针图片识别为 123。包内编译代码已核对包含导出优化和线程退出修复，EXE 时间戳晚于程序、打包脚本及测试源码。最终验收记录见 `diag_output/export_performance/package_verification.json`。

**总结**

这次提速来自减少大图渲染中的临时分配和像素复制，没有降低图片输出质量。三种 12.2MP 基础样本的导出总耗时约减少三分之一；复杂素材路径的收益更小。目录式分发消除了每次启动解包整套依赖的步骤，同时补齐了启动后快速关闭时的线程退出保护。
